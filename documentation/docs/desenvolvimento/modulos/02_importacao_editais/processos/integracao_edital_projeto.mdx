# Sincronizar Projetos dos Editais

Processo responsável por sincronizar os projetos e suas alocações dos Editais Selecionados

<BpmnViewer diagramUrl="/diagrams/integracao_edital.bpmn" height="300px"/>

## Integrar Projetos do Edital

Periodicamente, o **Agente Integrador**, executa esse subprocesso para sincronizar os dados de Editais com o status **Não Importado** e **Importado** no Conecta Fapes.

## Atualizar dados do Edital no Conecta Fapes

Após atualizar os editais, com os dados de Projeto e Alocação, os editais recebem o status "Importado".
