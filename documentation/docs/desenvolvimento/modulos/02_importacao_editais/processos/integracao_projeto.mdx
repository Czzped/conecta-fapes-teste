# Integrar Projetos

Processo responsável por sincronizar os dados de um projeto, suas alocações e seus bolsistas

<BpmnViewer diagramUrl="/diagrams/integracao_projetos.bpmn" height="200px"/>

## Buscar Projetos de um Edital no SigFapes

Busca todos os projetos de um edital conforma apresentado em [Buscar Projetos](https://documenter.getpostman.com/view/4242228/2sA3s3HBTC#intro).

## Atualizar os projetos no Conecta Fapes

Atualiza, ou cadastra novos projetos, no Conecta Fapes. Novos projetos são cadastrados com o status "Incompleto", enquanto os projetos já existentes são verificados se os dados cadastrais foram modificados. 

## Buscar as alocações no SigFapes

Busca os dados básicos de alocação de cada bolsistas apresentado em [Buscar Bolsistas do Projeto](https://documenter.getpostman.com/view/4242228/2sA3s3HBTC#intro).

## Atualizar Alocações no Conecta Fapes

Atualiza, ou aloca, um bolsista no Conecta Fapes.

## Buscar Bolsisas no SigFapes

Busca mais dados do bolsista conforme apresentado em [Dados do Bolsista](https://documenter.getpostman.com/view/4242228/2sA3s3HBTC#intro).

## Atualizar Bolsisas no Conecta Fapes

Atualiza os dados de um ou mais bolsistas no Conecta Fapes.
