## Levantar os processo que atendem ao objetivo do projeto

Levantar junto aos clientes quais processos são executados para atingir os objetivos organizacionais definidos que devem ser atingidos no projeto.

Artefatos produzidos:

* Lista de processos e quais objetivos esses atendem.

## Criar os processos AS IS

Modelar os processos identificados, com atividades, papéis e ferramentas utilizadas.

Artefatos produzidos:

* Modelos dos processos identificados, com informações de performance (e.g., tempo e custo de cada processos).

## Analisar os processo AS IS e propor melhorias nos processos

Analisar e propor melhorias nos processos modelados focando em melhorar as performances levantas anteriormente.

Artefatos produzidos:

* Novos modelos de processos (TO BE) com hipoteses de melhoriasde performance (e.g., tempo e custo de cada processos).

## Validar os processos TO BE com os clientes

Validar com os clientes os novos modelos de processos e fazer mudanças, caso seja necessário.

Artefatos produzidos:

* Novos modelos de processos (TO BE) validados.
