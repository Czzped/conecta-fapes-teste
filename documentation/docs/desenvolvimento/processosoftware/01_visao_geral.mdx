## Mapear Processo de Negócio do Cliente

Criar um modelo de processo de negócio que permita entender (As IS) as atividades do cliente para executar um objetivo organizacional.
Além disso, é permito realizar melhorias no processo (TO BE) do cliente, tomanda como base o sistema que será desenvolvido

Possiveis artefatos produzidos:

* Modelo AS IS: Descreve as atividades que são executadas atualmente, para entender a realidade atual da organização.

* Modelo TO BE: Descreve as atividades que serão executadas  futuramente, com melhorias trazidas pelo sistema ou outro artefato.

## Definir Produto a ser desenvolvido com escopo minimo definido

Definir o escopo minimo do produto (e.g., software e módulo) que será desenvolvido para atender os objetivos organizacionais que foram mapeados no processo, utilizando as informações do TO BE.

Artefatos produzidos:

* Um definição de escopo mínimo do produto
* Objetivos de peformance e custo que o produto deve atender.

## Realizar Processo de Design Sprint do Produto 

Realizar o processo de design sprint para entender em detalhes o produto que será desenvolvido.

Artefatos produzidos:

* Backlog mínimo, aplicando pareto (80/20)
* Telas e Regras de negócios especificadas.
* Cronograma de desenvolvimento de 3 meses.

## Realizar Processo de Desenvolvimento de Produto 

Realizar o processo de desenvolvimento do produto conforme acordado no planejamento

Artefatos produzidos:

* Produto funcionando conforme especificado.

## Realizar Processo de Garantia da Qualidade

Realizar o processo de garantia de qualidade, visando encontrar melhorias no produto que está sendo desenvolvido.

Artefatos produzidos:

* Produto funcionando conforme a qualidade especificada.

## Realizar Processo de Entrega e Monitoramento do Produto

Realizar o processo de entrega do produto e monitoramento do produto desenvolvido nos ambientes de produção. 

Artefatos produzidos:

* Artefatos que garantam a entrega do produto em ambiente de produção.
* Monitotamento do produto
