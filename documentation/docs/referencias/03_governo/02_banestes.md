# Arquivos do Banestes 
Documentos relativos aos arquivos (remessa e retorno) de pagamento de salário via Banestes

1) [Layout do Arquivo Remessa e Retorno](https://banestes.com.br/downloads/arquivos/layout_arquivo_magnetico_sist_sipfolhapagamentos.pdf): Documento com a especificação do arquivo remessa e retorno que será usado para a comunicação de pagamento do banestes.
2) [Site com exemplo de Layout de Arquivos](https://banestes.com.br/downloads/index.html): Site com exemplos de arquivos que podem ser usados para realizar a comunicação com o banestes via arquivo.
