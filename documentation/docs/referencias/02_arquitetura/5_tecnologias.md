# Tecnologia

Tecnologias utilizadas no projeto.

## Front-End

* [**Vue 3**](https://br.vuejs.org/):Vue (pronuncia-se /vjuː/, como view, em inglês) é um framework progressivo para a construção de interfaces de usuário. Ao contrário de outros frameworks monolíticos, Vue foi projetado desde sua concepção para ser adotável incrementalmente. A biblioteca principal é focada exclusivamente na camada visual (view layer), sendo fácil adotar e integrar com outras bibliotecas ou projetos existentes. 

* [**Vuetifyjs 3**](https://vuetifyjs.com/en/): uma biblioteca de componentes UI (User Interface) para Vue.js, um dos frameworks JavaScript mais populares para construção de interfaces de usuário. Desenvolvida com foco em design material, a biblioteca é amplamente utilizada para criar aplicativos web de alta qualidade e responsivos.

* [**Pinia**](https://pinia.vuejs.org/): uma biblioteca de gerenciamento de estado para Vue.js, projetada para ser uma alternativa moderna e mais eficiente ao Vuex, a biblioteca oficial de gerenciamento de estado do Vue.js. Pinia foi criada para oferecer uma API mais intuitiva e uma melhor experiência de desenvolvimento, aproveitando ao máximo os recursos da nova versão do Vue.js (Vue 3).

* [**Nuxt 2**](https://nuxt.com/): um framework de aplicativo Vue.js para desenvolvimento de aplicações web modernas. Ele se baseia no Vue.js e fornece uma estrutura poderosa para construir aplicações universais (server-side rendered) e estáticas.

* [**Vite**](https://vitejs.dev/): um construtor de aplicações web extremamente rápido e leve, desenvolvido especificamente para projetos Vue.js e React, embora também seja compatível com outros frameworks e bibliotecas JavaScript.

* [**Story Book**](https://storybook.js.org/):uma ferramenta de código aberto para o desenvolvimento de componentes de interface de usuário (UI). Ele permite que os desenvolvedores criem, visualizem e testem componentes de forma isolada, fora do contexto de uma aplicação maior. Em essência, o Storybook funciona como um ambiente de sandbox para componentes, onde você pode desenvolver e interagir com eles de maneira independente.

## Back-End

*  **C#**: C# (pronunciado "C Sharp") é uma linguagem de programação moderna, orientada a objetos e de propósito geral, desenvolvida pela Microsoft. É amplamente utilizada para desenvolver uma variedade de aplicações, incluindo aplicações de desktop, web, móveis, jogos e sistemas distribuídos.

* **.Net 8**: Plataforma de desenvolvimento de software criada pela Microsoft.

* [**OData**](https://www.odata.org/): SQl SeOData (Open Data Protocol) é um protocolo padrão para a criação e consumo de APIs RESTful, que facilita a manipulação de dados através da web. Ele foi originalmente desenvolvido pela Microsoft e agora é mantido pela OASIS (Organization for the Advancement of Structured Information Standards). OData define um conjunto de melhores práticas para a construção e consumo de APIs que permitem operações CRUD (Create, Read, Update, Delete) sobre recursos de dados. 

* **SQL Server**: um sistema de gerenciamento de banco de dados relacional (RDBMS) desenvolvido pela Microsoft. É um dos bancos de dados mais populares no mercado, utilizado por empresas de todos os portes para armazenar, gerenciar e recuperar dados.

* [**Entity Framework Core**](https://learn.microsoft.com/pt-br/ef/c): um mapeador moderno de relação de objetos que permite criar uma camada de acesso a dados limpa, portátil e de alto nível com o .NET (C#) em vários bancos de dados, incluindo o Banco de Dados SQL (local e o Azure), SQLite, MySQL, PostgreSQL e Azure Cosmos DB. Ele dá suporte a consultas LINQ, controle de alterações, atualizações e migrações de esquema.

* [**OPA**](https://www.openpolicyagent.org/): é um sistema de código aberto desenvolvido para implementar políticas de controle de acesso e gerenciamento de regras em diversas plataformas e serviços. Ele permite a definição, implementação e aplicação de políticas de maneira centralizada e consistente em todo o ecossistema de uma organização. Aqui estão os principais aspectos e funcionalidades do OPA.

## Infraestrutura

* **[3scale API Management](https://developers.redhat.com/products/3scale/overview)**: Red Hat 3scale API Management facilita a gestão das suas APIs para usuários internos ou externos. Compartilhe, proteja, distribua, controle e monetize suas APIs em uma plataforma de infraestrutura projetada com foco em desempenho, controle do cliente e crescimento futuro.

* **[Gitlab](https://gitlab.com/)**: uma plataforma completa de DevOps que oferece um conjunto integrado de ferramentas para gerenciar o ciclo de vida do desenvolvimento de software.

* **[kubernetes](https://kubernetes.io/)**: uma plataforma open-source de orquestração de contêineres, desenvolvida originalmente pelo Google. Ela automatiza a implantação, o dimensionamento e a operação de aplicações em contêineres, oferecendo um ambiente eficiente para gerenciar cargas de trabalho baseadas em contêineres em escala.

* **[Drone](https://www.drone.io/)**: uma plataforma de integração contínua (Continuous Integration - CI) e entrega contínua (Continuous Delivery - CD) que é projetada para automatizar o processo de construção, teste e implantação de software. 

* **[ArgoCD](https://argoproj.github.io/cd/)**: uma ferramenta de código aberto projetada para implementação contínua (Continuous Deployment) de aplicações Kubernetes. Ele automatiza o processo de implantação de aplicações para clusters Kubernetes, garantindo que o estado declarativo definido nos arquivos de configuração (como arquivos YAML) seja mantido no cluster alvo.
