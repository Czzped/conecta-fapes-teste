## Reunião de Sprint Planning Macro
 O Gestor apresenta para os líderes de cada Squad um documento apresentando os objetivos e metas do projeto. Esse documento será no formado six paper memo. 

## Reunião de Sprint Planning Detalhados
Cada líder  reune com a equipe para realizar um planejamento detalhado para os objetivos e metas do projeto, definindo indicadores e marcos de entrega. 

## Definição do Cronograma Macro
Os líders e o Coodenador do projeto consolidam os cronogramas em um cronograma Macro do projeto e fazem os acordos das metas e indicadores para a entrega.

## Apresentação de resultados da equipe
Quinzenalmente, os líderes apresentam os resultados para o coordenador de projeto e discutem sobre os próximo passos e resolução de impedimentos.

## Reunião de Apresentação de Resultados pra os stakeholders
Mensalmente, o Coordenador do projeto apresenta os resultados para os stakeholders (e.g., líderes, patrocinadores e clientes) do projeto. Neste evento são discutidos os próximos passos e resolução de impedimentos.
