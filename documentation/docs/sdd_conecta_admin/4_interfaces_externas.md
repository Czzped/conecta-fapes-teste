## Acesso Cidadão 
Autenticação de usuários por meio do serviço OpenID Connect, integrado à API oficial do governo estadual para gerenciamento seguro de login e identidade.

:::info[Para mais informações, acesse:] 
- **Documentação para público geral -** https://docs.acessocidadao.es.gov.br/ 
- **Documentação para desenvolvedores -** https://docs.developer.acessocidadao.es.gov.br/
:::

## SigFapes
Integração com o sistema SigFapes para importação automática de dados referentes a editais, projetos e bolsistas, alimentando diretamente o banco de dados da aplicação.
