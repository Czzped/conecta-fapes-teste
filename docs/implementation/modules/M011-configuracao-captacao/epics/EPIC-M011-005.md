## Contexto

Propostas habilitadas sao distribuidas para revisores ad hoc que avaliam o merito tecnico-cientifico. Cada revisor registra notas e parecer usando o formulario de avaliacao. As notas sao consolidadas para gerar ranking.

## Criterios de Aceitacao

- Analista distribui propostas habilitadas para revisores associados ao edital
- Revisor nao pode avaliar proposta da propria instituicao (RN03)
- Revisor registra notas e parecer usando formulario de avaliacao
- Sistema consolida notas de todos os revisores e gera ranking
