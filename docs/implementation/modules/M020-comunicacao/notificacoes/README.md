# Notificacoes

[<< Voltar ao M020](../README.md)

## Objetivo

Concentrar os artefatos do servico de notificacoes individuais do M020, incluindo templates transacionais, padroes de assunto, corpo de email e variaveis usadas pelos eventos de negocio dos demais modulos.

## Artefatos

| Documento | Descricao |
|-----------|-----------|
| [Catalogo de Eventos de Notificacao](catalogo-eventos.md) | Indice consolidado de todos os eventos de negocio que disparam email/notificacao, por modulo de origem: gatilho, tipo, destinatario, canal e mandatoriedade |
| [Template de Email - Notificacao de Evento](emails/email-notificacao-evento.md) | Design base para emails enviados quando eventos como alocacao de bolsista, pagamento planejado ou pagamento realizado acontecem no sistema |

## Escopo

Este contexto cobre notificacoes individuais disparadas por eventos do sistema. Comunicados em massa e lembretes automaticos continuam documentados nos EPICs gerais do M020.
