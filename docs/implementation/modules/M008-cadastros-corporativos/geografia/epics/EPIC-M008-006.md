## Contexto

Instituicoes, editais, programas e relatorios precisam de cadastros territoriais consistentes. Este submodulo agrupa `Cidade` e `Regiao`.

## Objetivo

Manter cidades e regioes de forma canonica, permitindo agrupamento territorial e filtros geograficos nos modulos consumidores.

## Cenarios BDD

```gherkin
Funcionalidade: Gerenciar cadastros geograficos

  Cenario: Cadastro de regiao
    Dado que o Analista esta autenticado
    Quando cadastra a regiao "Grande Vitoria"
    Entao o sistema salva a regiao

  Cenario: Cadastro de cidade vinculada a regiao
    Dado que a regiao "Grande Vitoria" existe
    Quando o Analista cadastra a cidade "Vitoria" com codigo IBGE "3205309"
    Entao o sistema salva a cidade vinculada a regiao

  Cenario: Bloquear codigo IBGE duplicado
    Dado que ja existe cidade com codigo IBGE "3205309"
    Quando o Analista tenta cadastrar outra cidade com o mesmo codigo
    Entao o sistema bloqueia o cadastro
```
