## Contexto

A agencia de fomento interage com milhares de pessoas fisicas -- pesquisadores, bolsistas, consultores ad hoc, coordenadores de projeto -- e precisa manter registros confiaveis sobre cada um deles. Atualmente, esses dados estao dispersos em planilhas, e-mails e sistemas legados, sem validacao de unicidade (CPF) e sem historico de alteracoes. Isso gera duplicidade de cadastros, dados desatualizados e impossibilidade de rastrear suspensoes ou bloqueios.

Sem um cadastro centralizado de pessoas, todos os demais modulos (editais, bolsas, pagamentos) operam sobre dados frageis, sujeitos a inconsistencias.

Este EPIC e fundacional do modulo M008: sem pessoas cadastradas, nenhum vinculo com instituicoes, projetos ou bolsas pode ser estabelecido.

## Objetivo

Permitir o cadastro, consulta, atualizacao e suspensao de pessoas fisicas, garantindo unicidade por CPF, historico de alteracoes e integracao com o Acesso Cidadao para auto-cadastro.

### US-M008-001: Cadastrar Pessoa Fisica

Como Servidor da Area Tecnica,
quero cadastrar uma pessoa fisica informando CPF, nome, email, data de nascimento e demais dados,
para que ela possa ser vinculada a projetos, bolsas e demais operacoes da agencia de fomento.

```gherkin
Funcionalidade: Cadastrar Pessoa Fisica

  Cenario: Cadastro com dados validos
    Dado que o Servidor da Area Tecnica esta autenticado
    E acessa a tela de cadastro de pessoas
    Quando informa o CPF "12345678901", nome "Joao da Silva", email "joao@email.com" e data de nascimento "1990-05-15"
    E confirma o cadastro
    Entao o sistema salva a pessoa com estado "Ativa"
    E registra o evento de cadastro no historico

  Cenario: Cadastro com CPF duplicado
    Dado que ja existe uma pessoa cadastrada com CPF "12345678901"
    Quando o Servidor tenta cadastrar outra pessoa com o mesmo CPF
    Entao o sistema exibe mensagem de erro informando que o CPF ja esta cadastrado (RN01)

  Cenario: Cadastro com dados obrigatorios ausentes
    Dado que o Servidor esta na tela de cadastro de pessoas
    Quando tenta salvar sem informar o nome
    Entao o sistema exibe mensagem de validacao indicando os campos obrigatorios

  Cenario: Auto-cadastro via Acesso Cidadao
    Dado que um usuario autenticou-se via Acesso Cidadao pela primeira vez
    E nao existe pessoa cadastrada com o CPF informado pelo SSO
    Quando o sistema recebe os dados da autenticacao
    Entao cria automaticamente o cadastro da pessoa com os dados recebidos (RN10)
    E registra o evento de cadastro automatico no historico
```

### US-M008-002: Listar e Consultar Pessoas

Como Servidor da Area Tecnica,
quero listar e consultar pessoas cadastradas,
para que eu possa localizar registros existentes antes de realizar operacoes.

```gherkin
Funcionalidade: Listar e Consultar Pessoas

  Cenario: Listagem de pessoas cadastradas
    Dado que existem pessoas cadastradas
    Quando o Servidor acessa a listagem de pessoas
    Entao o sistema exibe nome, CPF, email e estado de cada pessoa

  Cenario: Filtro por nome ou CPF
    Dado que existem pessoas cadastradas
    Quando o Servidor informa o filtro "Silva"
    Entao o sistema exibe apenas as pessoas cujo nome contem "Silva"

  Cenario: Consultar detalhes de uma pessoa
    Dado que o Servidor selecionou uma pessoa na listagem
    Quando acessa os detalhes
    Entao o sistema exibe todos os dados cadastrais e o historico de eventos
```

### US-M008-003: Atualizar Pessoa Fisica

Como Servidor da Area Tecnica,
quero atualizar os dados de uma pessoa fisica cadastrada,
para que informacoes incorretas ou desatualizadas sejam corrigidas.

```gherkin
Funcionalidade: Atualizar Pessoa Fisica

  Cenario: Atualizacao com dados validos
    Dado que a pessoa com CPF "12345678901" esta cadastrada
    Quando o Servidor altera o email para "joao.novo@email.com"
    E confirma a alteracao
    Entao o sistema salva as alteracoes
    E registra o evento de atualizacao no historico

  Cenario: Atualizacao com dados invalidos
    Dado que a pessoa esta cadastrada
    Quando o Servidor limpa o campo nome
    E tenta salvar
    Entao o sistema exibe mensagem de validacao indicando os campos obrigatorios

  Cenario: Atualizacao de pessoa suspensa
    Dado que a pessoa esta com estado "Suspensa"
    Quando o Servidor tenta atualizar os dados
    Entao o sistema permite a atualizacao cadastral
    E mantem o estado "Suspensa"
```

### US-M008-004: Suspender Pessoa

Como Servidor da Area Tecnica,
quero suspender uma pessoa fisica com justificativa,
para que todas as operacoes vinculadas a ela sejam bloqueadas ate regularizacao.

```gherkin
Funcionalidade: Suspender Pessoa

  Cenario: Suspensao com justificativa
    Dado que a pessoa esta com estado "Ativa"
    Quando o Servidor solicita a suspensao informando justificativa "Inadimplencia com prestacao de contas"
    E confirma a acao
    Entao o sistema altera o estado para "Suspensa"
    E registra o evento de suspensao no historico com a justificativa
    E bloqueia operacoes vinculadas (RN05)

  Cenario: Suspensao sem justificativa
    Dado que a pessoa esta com estado "Ativa"
    Quando o Servidor tenta suspender sem informar justificativa
    Entao o sistema exibe mensagem informando que a justificativa e obrigatoria

  Cenario: Reativacao de pessoa suspensa
    Dado que a pessoa esta com estado "Suspensa"
    Quando o Servidor solicita a reativacao informando justificativa "Situacao regularizada"
    E confirma a acao
    Entao o sistema altera o estado para "Ativa"
    E registra o evento de reativacao no historico (RI2)
    E desbloqueia operacoes vinculadas
```
