## Contexto

Apos a contratacao de projetos, diferentes perfis da agencia de fomento precisam acompanhar a execucao. O coordenador precisa saber o status das entregas e prazos do seu projeto. A Area Tecnica da agencia de fomento precisa de uma visao gerencial de todos os projetos. A SECONT (auditoria externa) precisa consultar informacoes para fins de fiscalizacao.

Atualmente, nao existe um dashboard consolidado. As informacoes estao dispersas em planilhas, e-mails e documentos avulsos. Cada perfil precisa compilar manualmente os dados necessarios, o que gera atrasos na tomada de decisao e falta de visibilidade sobre projetos com problemas.

Este EPIC e o fundacional do modulo M012: os dashboards consolidam as informacoes que servem de base para as acoes de gestao de relatorios e solicitacoes de alteracao.

## Objetivo

Prover dashboards de acompanhamento com visoes especificas para coordenador, agencia de fomento e SECONT, permitindo o monitoramento consolidado da execucao dos projetos contratados.

### US-M012-001: Dashboard Coordenador

Como Coordenador do Projeto,
quero visualizar um dashboard com o status consolidado do meu projeto,
para que eu possa acompanhar prazos, entregas pendentes e solicitacoes em andamento.

```gherkin
Funcionalidade: Dashboard Coordenador

  Cenario: Visualizacao do dashboard com projetos ativos
    Dado que o Coordenador esta autenticado
    E possui projetos contratados
    Quando acessa o dashboard de acompanhamento
    Entao o sistema exibe a lista de seus projetos com titulo, status, data de inicio, data prevista de fim
    E exibe indicadores de relatorios pendentes, submetidos e solicitacoes em andamento

  Cenario: Detalhamento de projeto
    Dado que o Coordenador selecionou um projeto no dashboard
    Quando acessa os detalhes
    Entao o sistema exibe cronograma de entregas, relatorios submetidos com status e solicitacoes de alteracao com status

  Cenario: Dashboard sem projetos contratados
    Dado que o Coordenador nao possui projetos contratados
    Quando acessa o dashboard
    Entao o sistema exibe mensagem informando que nao ha projetos contratados para acompanhamento (RN01)

  Cenario: Alerta de relatorio pendente
    Dado que o Coordenador possui relatorio tecnico com prazo proximo
    Quando acessa o dashboard
    Entao o sistema destaca o relatorio pendente com alerta visual
```

### US-M012-002: Dashboard da agencia de fomento

Como Servidor da Area Tecnica da agencia de fomento,
quero visualizar um dashboard gerencial com todos os projetos em acompanhamento,
para que eu possa identificar projetos com pendencias e priorizar minhas atividades.

```gherkin
Funcionalidade: Dashboard da agencia de fomento

  Cenario: Visualizacao do dashboard gerencial
    Dado que o Servidor da Area Tecnica esta autenticado
    Quando acessa o dashboard da agencia de fomento
    Entao o sistema exibe todos os projetos contratados com titulo, coordenador, status, data de inicio e data prevista de fim
    E exibe indicadores consolidados de relatorios pendentes de analise e solicitacoes pendentes

  Cenario: Filtro por status do projeto
    Dado que existem projetos em diferentes status
    Quando o Servidor filtra por status "Ativo"
    Entao o sistema exibe apenas os projetos com status ativo

  Cenario: Filtro por edital
    Dado que existem projetos de diferentes editais
    Quando o Servidor filtra por edital "EDT-2026-001"
    Entao o sistema exibe apenas os projetos vinculados ao edital selecionado

  Cenario: Listagem de relatorios pendentes de analise
    Dado que existem relatorios tecnicos com status "Submetido"
    Quando o Servidor acessa a secao de relatorios pendentes
    Entao o sistema exibe a lista de relatorios aguardando analise, ordenados por data de submissao
```

### US-M012-003: Dashboard SECONT

Como Servidor da SECONT,
quero visualizar um dashboard somente-leitura com informacoes dos projetos financiados,
para que eu possa realizar fiscalizacao e auditoria sem intervir nos processos.

```gherkin
Funcionalidade: Dashboard SECONT

  Cenario: Visualizacao do dashboard de auditoria
    Dado que o Servidor da SECONT esta autenticado
    Quando acessa o dashboard SECONT
    Entao o sistema exibe todos os projetos contratados com titulo, coordenador, valor financiado, status e datas
    E exibe indicadores consolidados de execucao

  Cenario: Consulta de detalhes do projeto
    Dado que o Servidor da SECONT selecionou um projeto
    Quando acessa os detalhes
    Entao o sistema exibe relatorios submetidos, pareceres emitidos, solicitacoes de alteracao e decisoes

  Cenario: Restricao de edicao
    Dado que o Servidor da SECONT esta no dashboard
    Quando tenta realizar qualquer acao de edicao
    Entao o sistema impede a acao
    E exibe mensagem informando que o perfil SECONT e somente-leitura (RN04)

  Cenario: Exportacao de dados
    Dado que o Servidor da SECONT esta no dashboard
    Quando solicita a exportacao dos dados
    Entao o sistema gera um relatorio consolidado para download
```
