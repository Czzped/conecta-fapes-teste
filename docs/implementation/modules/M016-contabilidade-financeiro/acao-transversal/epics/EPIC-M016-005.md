# EPIC-M016-005: Politicas e Faixas de Acao Transversal

[<< Voltar aos Epicos](README.md)

## Contexto

A Resolucao CCAF nº 334/2023 define percentuais de Acao Transversal por faixa de valor. Esses parametros devem ser cadastrados como politica normativa versionada, e nao fixados no codigo, para permitir mudancas futuras sem perder o historico aplicado a reservas anteriores.

## Objetivo

Permitir que o Gestor Financeiro cadastre politicas, vigencias, base legal, faixas percentuais e rubricas permitidas da Acao Transversal.

```gherkin
Funcionalidade: Politicas e faixas de Acao Transversal

  Cenario: Cadastrar politica da Resolucao CCAF 334/2023
    Dado que o Gestor Financeiro esta autenticado
    Quando cadastra a politica "Resolucao CCAF 334/2023"
    E informa vigencia, base legal e rubricas permitidas
    E informa as faixas 5%, 4% e 3%
    Entao o sistema salva a politica
    E permite sua ativacao

  Cenario: Impedir politicas vigentes sobrepostas
    Dado que existe politica vigente para a data atual
    Quando o Gestor tenta ativar outra politica com vigencia sobreposta
    Entao o sistema rejeita a ativacao

  Cenario: M010 consulta politica vigente
    Dado que existe politica ativa para a data do aporte
    Quando o M010 solicita a regra aplicavel
    Entao o M016 retorna a politica, faixas e rubricas permitidas
```

## Regras

| ID | Regra |
|----|-------|
| RN-AT-POL-01 | So pode existir uma politica ativa por periodo de vigencia. |
| RN-AT-POL-02 | Faixas da mesma politica nao podem se sobrepor. |
| RN-AT-POL-03 | Reservas ja calculadas mantem snapshot da politica aplicada mesmo apos alteracoes normativas. |
