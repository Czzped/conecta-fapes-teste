# EPIC-M016-008: Plano de Aplicacao e Execucao de Despesas da Acao Transversal

[<< Voltar aos Epicos](README.md)

## Contexto

Com a `TaxaGestaoParcerias` vinculada a uma `AcaoTransversal` via `OutorgaAcaoTransversal`, o Coordenador Outorgado pode elaborar o plano de aplicacao por rubricas permitidas e registrar as despesas institucionais com documentos comprobatorios.

## Objetivo

Permitir planejar o uso dos recursos da AcaoTransversal por rubrica e registrar despesas institucionais vinculadas ao plano, com rastreabilidade de documento e justificativa.

```gherkin
Funcionalidade: Plano de aplicacao e execucao da Acao Transversal

  Cenario: Plano dentro do saldo vinculado
    Dado que existe AcaoTransversal com TaxaGestaoParcerias vinculada de R$ 50.000,00
    Quando o Gestor Financeiro distribui o valor em rubricas permitidas
    Entao o sistema salva o PlanoAplicacaoAT
    E impede que o totalPlanejado ultrapasse o saldo disponivel (INV-AT03)

  Cenario: Rejeitar rubrica nao permitida no plano
    Dado que a rubrica "INFRA-999" nao consta em VersaoPoliticaTaxaGestao.rubricasPermitidas
    Quando o Gestor tenta incluir a rubrica no plano
    Entao o sistema rejeita com "Rubrica nao autorizada pela politica vigente" (INV-AT02)

  Cenario: Registrar despesa com documento
    Dado que existe PlanoAplicacaoAT aprovado
    Quando o Coordenador Outorgado registra despesa com rubrica permitida e documento comprobatorio
    Entao a DespesaAcaoTransversal e registrada em estado LANCADA
    E o saldo executado da AcaoTransversal e atualizado

  Cenario: Rejeitar despesa acima do saldo do item do plano
    Dado que ItemPlanoAplicacaoAT tem valorPlanejado = R$ 10.000,00 ja totalmente executado
    Quando o Coordenador registra nova despesa de R$ 1.000,00 nessa rubrica
    Entao o sistema rejeita por saldo insuficiente no item do plano

  # --- Cenarios de Erro ---

  Cenario: Rejeitar PlanoAplicacaoAT para AcaoTransversal sem outorga vigente
    Dado que existe AcaoTransversal com estado EM_ELABORACAO sem OutorgaAcaoTransversal VIGENTE
    Quando o Gestor tenta criar PlanoAplicacaoAT para essa AcaoTransversal
    Entao o sistema rejeita com "AcaoTransversal deve estar ATIVA (com OutorgaAcaoTransversal vigente) para elaborar plano de aplicacao. Estado atual: EM_ELABORACAO"

  Cenario: Rejeitar DespesaAcaoTransversal com PlanoAplicacaoAT nao aprovado
    Dado que existe PlanoAplicacaoAT com estado RASCUNHO (nao aprovado)
    Quando o Coordenador Outorgado tenta registrar despesa vinculada a esse plano
    Entao o sistema rejeita com "Despesa so pode ser registrada contra PlanoAplicacaoAT aprovado. Estado atual do plano: RASCUNHO" (INV-AT07)

  Cenario: Rejeitar modificacao de PlanoAplicacaoAT ja aprovado
    Dado que existe PlanoAplicacaoAT com estado APROVADO
    Quando o Gestor tenta alterar valorPlanejado de um ItemPlanoAplicacaoAT
    Entao o sistema rejeita com "PlanoAplicacaoAT aprovado nao pode ser modificado. Solicite revisao para alterar o plano."

  Cenario: Rejeitar DespesaAcaoTransversal com valor zero ou negativo
    Dado que existe PlanoAplicacaoAT aprovado com saldo disponivel
    Quando o Coordenador registra DespesaAcaoTransversal com valor = R$ 0,00
    Entao o sistema rejeita com "Valor da despesa deve ser maior que zero" (INV-AT04)

  Cenario: Rejeitar DespesaAcaoTransversal sem justificativa
    Dado que existe PlanoAplicacaoAT aprovado
    Quando o Coordenador tenta registrar DespesaAcaoTransversal com campo justificativa vazio
    Entao o sistema rejeita com "Justificativa e obrigatoria para registro de despesa institucional"
```

## Regras

| ID | Regra |
|----|-------|
| RN-AT-EXE-01 | PlanoAplicacaoAT.totalPlanejado nao pode superar SUM(OutorgaAcaoTransversal.valorVinculado) para a AcaoTransversal (INV-AT03). |
| RN-AT-EXE-02 | Todo item do plano deve usar rubrica em VersaoPoliticaTaxaGestao.rubricasPermitidas (INV-AT02). |
| RN-AT-EXE-03 | Toda despesa exige rubrica permitida, documento comprobatorio e justificativa. |
| RN-AT-EXE-04 | Despesa nao pode gerar saldo negativo na rubrica do plano. |
| RN-AT-EXE-05 | `PlanoAplicacaoAT` aprovado e imutavel — alteracoes exigem transicao para EM_REVISAO. |
| RN-AT-EXE-06 | `DespesaAcaoTransversal` so pode ser registrada com `PlanoAplicacaoAT.estado = APROVADO` (INV-AT07) e valor > 0 (INV-AT04). |

## Entidades

| Entidade | Papel |
|----------|-------|
| `AcaoTransversal` | Projeto institucional que recebe e executa os recursos. |
| `OutorgaAcaoTransversal` | Autoriza Coordenador Outorgado a gerir a AcaoTransversal. |
| `PlanoAplicacaoAT` | Distribuicao por rubrica do saldo vinculado. |
| `ItemPlanoAplicacaoAT` | Linha por rubrica dentro do plano. |
| `DespesaAcaoTransversal` | Despesa executada; reduz saldo do item do plano. |
| `TaxaGestaoParcerias` | Origem do recurso; custodiada em `taxa-gestao/`. |
