# EPIC-M016-010: Dashboard e Relatorios da Acao Transversal

[<< Voltar aos Epicos](README.md)

## Contexto

Gestores precisam acompanhar o ciclo de vida das AcoesTransversais: recursos vinculados, planos aprovados, despesas executadas, glosas e prestacoes pendentes. Diferente do dashboard de Taxa de Gestao (EPIC-M016-015), este foca na **execucao dos recursos** — o que foi planejado, executado e aprovado dentro de cada AcaoTransversal.

## Objetivo

Disponibilizar consultas, dashboards e exportacoes gerenciais do ciclo de execucao da AcaoTransversal: plano, despesas, glosas, prestacoes e saldos.

```gherkin
Funcionalidade: Dashboard e relatorios da Acao Transversal

  Cenario: Exibir consolidado por AcaoTransversal
    Dado que existem AcoesTransversais em diferentes estados
    Quando o Gestor acessa o dashboard
    Entao o sistema exibe: vinculado, planejado, executado, aprovado, glosado e saldo por AcaoTransversal

  Cenario: Filtrar por Coordenador Outorgado
    Dado que existem OutorgasAcaoTransversal para diferentes servidores FAPES
    Quando o Gestor filtra por Coordenador Outorgado
    Entao o sistema exibe apenas AcoesTransversais, repasses e prestacoes do outorgado selecionado

  Cenario: Exibir alertas de prestacao pendente
    Dado que existem PrestacaoContasAcaoTransversal em EM_ANALISE ha mais de 30 dias
    Quando o Gestor acessa o dashboard
    Entao o sistema exibe alerta de prestacao pendente com nome do Coordenador e AcaoTransversal

  Cenario: Exportar relatorio de prestacao gerencial
    Dado que o Gestor aplicou filtros por periodo e AcaoTransversal
    Quando solicita exportacao
    Entao o sistema gera arquivo com: AcaoTransversal, OutorgaAcaoTransversal, Coordenador Outorgado,
      totalVinculado, totalPlanejado, totalExecutado, totalGlosado, saldoRestante, estado
```

## Regras

| ID | Regra |
|----|-------|
| RN-AT-DASH-01 | Dashboard deve separar: vinculado (de TaxaGestaoParcerias), planejado (PlanoAplicacaoAT), executado (DespesaAcaoTransversal), aprovado e glosado (PrestacaoContasAcaoTransversal). |
| RN-AT-DASH-02 | Consultas devem permitir rastrear TaxaGestaoParcerias de origem, OutorgaAcaoTransversal e Coordenador Outorgado. |
| RN-AT-DASH-03 | Este dashboard foca execucao — para historico de versoes da politica e snapshot de taxas, ver EPIC-M016-015 (taxa-gestao). |
