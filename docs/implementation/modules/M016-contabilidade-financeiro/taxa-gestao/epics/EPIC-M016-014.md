# EPIC-M016-014: Vinculacao com AcaoTransversal

[<< Voltar aos Epicos](README.md)

## Contexto

Apos classificada, uma TaxaGestaoParcerias pode ser vinculada a uma ou mais AcoesTransversais via OutorgaAcaoTransversal. Uma AcaoTransversal pode receber recursos de multiplas taxas (N:N). Essa vinculacao transfere a responsabilidade de execucao do recurso para o subdominio AcaoTransversal.

## Objetivo

Registrar a vinculacao entre TaxaGestaoParcerias e AcaoTransversal, controlando o saldo disponivel e emitindo o sinal de que a taxa esta custodiada e pronta para execucao.

```gherkin
Funcionalidade: Vinculacao de TaxaGestaoParcerias com AcaoTransversal

  Cenario: Vincular taxa classificada a uma AcaoTransversal
    Dado que existe TaxaGestaoParcerias ja classificada (com ClassificacaoContabilTGP)
    E existe AcaoTransversal com estado EM_ELABORACAO ou ATIVA
    Quando o Gestor Financeiro vincula a taxa a AcaoTransversal
    Entao o sistema registra a vinculacao via OutorgaAcaoTransversal
    E registra a OutorgaAcaoTransversal (marco: vinculada)

  Cenario: Uma taxa pode financiar multiplas AcoesTransversais
    Dado que TaxaGestaoParcerias possui valorTaxaGestao = R$ 200.000,00
    Quando o Gestor vincula R$ 120.000,00 para AcaoTransversal "AT-001"
    E vincula R$ 80.000,00 para AcaoTransversal "AT-002"
    Entao ambas as vinculacoes sao registradas
    E saldo restante e R$ 0,00

  Cenario: Rejeitar vinculacao acima do saldo
    Dado que TaxaGestaoParcerias possui saldo disponivel de R$ 50.000,00
    Quando o Gestor tenta vincular R$ 70.000,00
    Entao o sistema rejeita por saldo insuficiente (INV-TGP01)

  Cenario: Consultar taxas que financiam uma AcaoTransversal
    Dado que AcaoTransversal "AT-001" recebe recursos de tres taxas
    Quando o Gestor consulta as origens da AcaoTransversal
    Entao o sistema lista as TaxaGestaoParcerias vinculadas com parceria de origem, versaoPoliticaSigla e valorVinculado

  # --- Cenarios de Erro ---

  Cenario: Rejeitar vinculacao de taxa ainda nao classificada
    Dado que existe TaxaGestaoParcerias ainda nao classificada (sem ClassificacaoContabilTGP)
    Quando o Gestor tenta vincular a taxa a uma AcaoTransversal
    Entao o sistema rejeita com "Vinculacao exige taxa ja classificada (ClassificacaoContabilTGP). Taxa ainda nao classificada." (RN-TGP-VIN-03)

  Cenario: Rejeitar vinculacao a AcaoTransversal encerrada ou cancelada
    Dado que existe AcaoTransversal com estado ENCERRADA
    Quando o Gestor tenta vincular TaxaGestaoParcerias a essa AcaoTransversal
    Entao o sistema rejeita com "AcaoTransversal deve estar EM_ELABORACAO ou ATIVA para receber vinculacao. Estado atual: ENCERRADA"

  Cenario: Rejeitar vinculacao com valor zero ou negativo
    Dado que TaxaGestaoParcerias possui saldo disponivel de R$ 100.000,00
    Quando o Gestor tenta vincular R$ 0,00 para AcaoTransversal
    Entao o sistema rejeita com "Valor vinculado deve ser maior que zero" (RN-TGP-VIN-04)

  Cenario: Rejeitar vinculacao duplicada da mesma taxa a mesma AcaoTransversal
    Dado que TaxaGestaoParcerias ja esta vinculada a AcaoTransversal "AT-001" via OutorgaAcaoTransversal
    Quando o Gestor tenta criar nova vinculacao da mesma taxa para "AT-001"
    Entao o sistema rejeita com "Esta TaxaGestaoParcerias ja esta vinculada a AcaoTransversal informada. Edite a OutorgaAcaoTransversal existente para ajustar o valor." (RN-TGP-VIN-04)
```

## Regras

| ID | Regra |
|----|-------|
| RN-TGP-VIN-01 | Uma TaxaGestaoParcerias pode financiar multiplas AcoesTransversais (N:N via OutorgaAcaoTransversal — INV-TGP01). |
| RN-TGP-VIN-02 | Total vinculado nao pode ultrapassar valorTaxaGestao disponivel. |
| RN-TGP-VIN-03 | Taxa deve estar ja classificada (com ClassificacaoContabilTGP) para ser vinculada. |
| RN-TGP-VIN-04 | Valor vinculado deve ser maior que zero; e nao pode haver vinculacao duplicada da mesma taxa para a mesma AcaoTransversal. |

## Entidades

| Entidade | Papel |
|----------|-------|
| `TaxaGestaoParcerias` | Origem do recurso; passa a ter OutorgaAcaoTransversal (marco: vinculada). |
| `AcaoTransversal` | Projeto que recebe o recurso para execucao. |
| `OutorgaAcaoTransversal` | Mediacao N:N entre taxa e acao; designa Coordenador Outorgado. |
