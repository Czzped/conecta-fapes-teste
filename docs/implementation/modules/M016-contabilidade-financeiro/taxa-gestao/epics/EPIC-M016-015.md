# EPIC-M016-015: Dashboard e Relatorios da Taxa de Gestao de Parcerias

[<< Voltar aos Epicos](README.md)

## Contexto

O Gestor Financeiro e a Diretoria precisam acompanhar o volume de taxas calculadas, classificadas, repassadas e vinculadas, consolidando por Parceria, versao da politica, faixa, periodo e estado. O historico de versoes da politica deve ser auditavel via snapshot desnormalizado.

## Objetivo

Fornecer dashboard e relatorios de acompanhamento do ciclo de vida das TaxaGestaoParcerias: calculadas, classificadas, repassadas, vinculadas e encerradas.

```gherkin
Funcionalidade: Dashboard e relatorios da Taxa de Gestao de Parcerias

  Cenario: Dashboard de taxas por estado
    Dado que existem TaxaGestaoParcerias em diferentes estados
    Quando o Gestor Financeiro acessa o dashboard
    Entao o sistema exibe contagem e valor total por estado: CALCULADA, CLASSIFICADA, REPASSADA, VINCULADA, ENCERRADA

  Cenario: Relatorio de taxas por Parceria
    Dado que uma Parceria tem multiplos aportes com taxas calculadas
    Quando o Gestor filtra por Parceria
    Entao o sistema lista cada TaxaGestaoParcerias com: dataAporte, versaoPoliticaSigla, faixaSigla, percentualAplicado, valorTaxaGestao, estado

  Cenario: Auditoria historica de versoes da politica
    Dado que existem taxas calculadas com TGP-2023 e TGP-2024
    Quando o Auditor consulta o historico
    Entao o sistema exibe cada taxa com o snapshot da versao usada, sem depender da politica vigente atual

  Cenario: Comparativo de impacto de nova Resolucao
    Dado que existem VersaoPoliticaTaxaGestao TGP-2023 (5%, 4%, 3%) e TGP-2024 (4%, 3%, 2%)
    Quando o Gestor simula o impacto da nova versao sobre aportes do periodo
    Entao o sistema calcula a diferenca de valorTaxaGestao que seria gerada
    E apresenta o comparativo sem alterar snapshots existentes

  Cenario: Relatorio de repasses por conta BANESTES
    Dado que existem repasses registrados em diferentes contas BANESTES
    Quando o Gestor filtra por periodo "2024-01 a 2024-12"
    Entao o sistema lista repasses com conta bancaria, titular, valor e Parceria de origem

  # --- Cenarios de Erro ---

  Cenario: Rejeitar filtro com dataFim anterior a dataInicio
    Dado que o Gestor esta consultando relatorio de taxas
    Quando informa dataInicio "2024-06-01" e dataFim "2024-01-01"
    Entao o sistema rejeita com "dataFim deve ser igual ou posterior a dataInicio no filtro de periodo"

  Cenario: Rejeitar operacao de escrita via endpoint de dashboard
    Dado que o Gestor Financeiro acessa endpoint de dashboard de TaxaGestaoParcerias
    Quando tenta submeter operacao de modificacao (PUT/POST/DELETE) via endpoint de consulta
    Entao o sistema rejeita com HTTP 405 Method Not Allowed
    E registra tentativa de escrita em audit log (RN-TGP-DASH-01)

  Cenario: Exportacao sem registros no periodo filtrado
    Dado que nenhuma TaxaGestaoParcerias existe para o periodo e filtros selecionados
    Quando o Gestor solicita exportacao
    Entao o sistema retorna aviso "Nenhum registro encontrado para os filtros aplicados"
    E nao retorna erro HTTP — exporta arquivo vazio com cabecalho
```

## Regras

| ID | Regra |
|----|-------|
| RN-TGP-DASH-01 | Dashboard deve exibir totais por estado sem alterar os dados de origem. |
| RN-TGP-DASH-02 | Auditoria historica usa snapshots desnormalizados (versaoPoliticaSigla, faixaSigla) — sem JOIN com politica vigente. |
| RN-TGP-DASH-03 | Simulacao de nova versao e operacao somente leitura — nunca recalcula taxas existentes. |
| RN-TGP-DASH-04 | Filtro de periodo invalido (dataFim < dataInicio) e rejeitado antes da consulta. Exportacao sem resultados retorna cabecalho, nao erro HTTP. |

## Entidades Consultadas
