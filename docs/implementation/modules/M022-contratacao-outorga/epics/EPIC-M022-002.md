# EPIC-M022-002 - Formalizacao da Contratacao e Outorga

## Objetivo

Controlar a conferencia de requisitos finais e a formalizacao do termo de outorga ou contrato.

## User Stories

### US-M022-003 - Conferir requisitos finais da contratacao

Como Area Tecnica, quero conferir os requisitos finais antes da formalizacao para evitar outorgas inconsistentes.

### US-M022-004 - Formalizar termo de outorga ou contrato

Como Area Tecnica, quero registrar termo, data de assinatura e outorgado para concluir a contratacao/outorga.

### US-M022-005 - Cancelar contratacao/outorga

Como Area Tecnica, quero cancelar uma contratacao/outorga com justificativa quando ela nao puder ser formalizada.
