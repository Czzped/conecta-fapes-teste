# EPIC-M022-001 - Convocacao de Propostas Aprovadas

## Objetivo

Permitir que a Area Tecnica consulte propostas aprovadas no resultado final da captacao e convoque aquelas que seguirao para contratacao/outorga.

## User Stories

### US-M022-001 - Listar propostas aprovadas no resultado final

Como Area Tecnica, quero listar propostas aprovadas no resultado final da captacao para iniciar a etapa de contratacao/outorga.

### US-M022-002 - Convocar proposta aprovada

Como Area Tecnica, quero convocar uma proposta aprovada para iniciar sua contratacao/outorga.
