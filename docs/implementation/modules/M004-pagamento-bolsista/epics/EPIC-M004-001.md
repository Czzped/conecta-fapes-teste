# EPIC-M004-001: Definir Calendario das Folhas

[← Voltar ao Sub-Backlog](../backlog.md)

## Contexto

O pagamento de bolsistas ocorre em ciclos mensais definidos por tres marcos: M1 (Data Limite de Solicitacao de Bolsas), M2 (Data Prevista de Geracao da Folha Normal) e M3 (Data de Pagamento da Folha Normal). Sem um calendario estruturado que defina esses marcos para cada mes, nao e possivel iniciar o processo de liberacao de editais nem a geracao de folhas de pagamento.

Hoje a definicao desses marcos e feita de forma manual e descentralizada, gerando inconsistencias nos prazos e dificuldades na coordenacao entre areas tecnicas e GEPOF.

Este EPIC e fundacional para o modulo M004: sem marcos definidos, nenhum dos demais processos de pagamento pode ser iniciado.

## Objetivo

Permitir que o Gerente GEPOF visualize e defina o calendario anual com os marcos M1, M2 e M3 para cada mes, respeitando as restricoes de datas e prazos.

### US-M004-001: Visualizar Calendario Anual

Como Gerente GEPOF,
quero visualizar o calendario anual com os marcos M1, M2 e M3 definidos para cada mes,
para que eu possa acompanhar e planejar os ciclos de pagamento.

```gherkin
Funcionalidade: Visualizar Calendario Anual

  Cenario: Exibicao do calendario do ano atual
    Dado que o Gerente GEPOF esta autenticado
    Quando acessa a tela de calendario de folhas
    Entao o sistema exibe o ano atual selecionado por padrao
    E exibe os marcos M1, M2 e M3 definidos para cada mes do ano

  Cenario: Selecao de outro ano
    Dado que o Gerente GEPOF esta na tela de calendario de folhas
    Quando seleciona o ano "2025"
    Entao o sistema exibe os marcos M1, M2 e M3 para cada mes de 2025

  Cenario: Calendario sem marcos definidos
    Dado que o Gerente GEPOF selecionou um ano sem marcos definidos
    Quando o sistema exibe o calendario
    Entao os campos de marcos aparecem vazios para cada mes
```

### US-M004-002: Definir Marcos da Folha

Como Gerente GEPOF,
quero definir ou alterar os marcos M1, M2 e M3 para cada mes do calendario,
para que os ciclos de pagamento sigam prazos consistentes e coordenados.

```gherkin
Funcionalidade: Definir Marcos da Folha

  Cenario: Definicao de marcos com datas validas
    Dado que o Gerente GEPOF visualiza o calendario do ano atual
    Quando define para o mes de Julho M1 como "2025-06-30", M2 como "2025-07-15" e M3 como "2025-07-31"
    E confirma a definicao
    Entao o sistema salva os marcos para Julho
    E o calendario exibe os marcos atualizados

  Cenario: M1 com data fora do intervalo permitido
    Dado que o Gerente GEPOF esta definindo marcos para Julho
    Quando informa M1 como "2025-05-15"
    Entao o sistema exibe mensagem de erro indicando que M1 deve ser uma data de Junho ou Julho

  Cenario: M2 com data fora do mes de competencia
    Dado que o Gerente GEPOF esta definindo marcos para Julho
    Quando informa M2 como "2025-08-01"
    Entao o sistema exibe mensagem de erro indicando que M2 deve ser uma data de Julho

  Cenario: M3 com data fora do intervalo permitido
    Dado que o Gerente GEPOF esta definindo marcos para Julho
    Quando informa M3 como "2025-09-01"
    Entao o sistema exibe mensagem de erro indicando que M3 deve ser uma data de Julho ou Agosto

  Cenario: Marcos com ordenacao invalida
    Dado que o Gerente GEPOF esta definindo marcos para Julho
    Quando informa M1 como "2025-07-20" e M2 como "2025-07-15"
    Entao o sistema exibe mensagem de erro indicando que M1 deve ocorrer antes de M2

  Cenario: Edicao de M1 apos prazo limite
    Dado que o marco M1 de Agosto esta definido como "2025-08-05"
    E a data atual e "2025-08-06"
    Quando o Gerente GEPOF tenta alterar o M1 de Agosto
    Entao o sistema impede a alteracao
    E exibe mensagem informando que o prazo para edicao de M1 ja expirou

  Cenario: Edicao de M2 apos prazo limite
    Dado que o marco M2 de Agosto esta definido como "2025-08-15"
    E a data atual e "2025-08-15"
    Quando o Gerente GEPOF tenta alterar o M2 de Agosto
    Entao o sistema impede a alteracao
    E exibe mensagem informando que o prazo para edicao de M2 ja expirou

  Cenario: Alerta de distancia insuficiente entre marcos
    Dado que o Gerente GEPOF esta definindo marcos para Julho
    Quando informa M1 como "2025-07-01" e M2 como "2025-07-04"
    Entao o sistema exibe alerta recomendando distancia maior que 5 dias entre M1 e M2

  Cenario: M2 conflitando com M1 do mes seguinte
    Dado que o marco M1 de Agosto esta definido como "2025-08-05"
    Quando o Gerente GEPOF define M2 de Julho como "2025-07-30"
    E M2 nao conflita com M1 de Agosto
    Entao o sistema salva o marco M2

  Cenario: Criacao de calendario para ano subsequente
    Dado que o Gerente GEPOF esta na tela de calendario
    Quando seleciona o ano subsequente ao atual
    Entao o sistema cria um novo calendario vazio para o ano selecionado
    E permite a definicao dos marcos para cada mes
```
