# EPIC-M003-005 — Consultar Visao Consolidada da Projeto

| Atributo | Valor |
|----------|-------|
| **Status** | To Do |
| **Prioridade** | Must |
| **Dependencias** | Transversal |
| **Operacao do contrato** | ConsultarProjetoConsolidada, ConsultarProjetosPorPrograma, ConsultarProjetosPorParceria |

## Contexto

Os modulos de planejamento, acompanhamento, suspensao, BI, transparencia e portais precisam consultar a projeto como objeto consolidado, sem depender de detalhes internos do plano, da execucao financeira ou de outros bounded contexts.

## User Stories

### US-M003-017 — Consultar projeto consolidada
Retorna dados estaveis da projeto, ortogado, plano vigente, resultados, cronograma, equipe e resumo financeiro.

Na visualizacao consolidada em **Projetos**, deve existir acesso a aba **Aditivos**, na qual sao listados os dados dos aditivos vinculados a projeto quando existirem. O detalhamento funcional da aba, seus campos e criterios de aceite estao definidos no [EPIC-M003-008 - Consultar Vigencia e Aditivos da Projeto](../aditivos/epics/EPIC-M003-008.md).

### US-M003-018 — Listar projetos por programa
Lista projetos associadas a um programa para consolidacao no M010.

### US-M003-019 — Listar projetos por parceria
Lista projetos associadas a uma parceria para acompanhamento financeiro e estrategico no M010.

### US-M003-020 — Listar projetos por estado
Permite consultar projetos por estado operacional, apoiando suspensao, encerramento, BI e transparencia.

### US-M003-042 — Visualizar acompanhamento orcamentario por rubrica no Meu Projeto
Como coordenador da projeto, quero visualizar o total, o consumido, o alocado quando aplicavel, o disponivel e os percentuais por rubrica, para acompanhar a execucao orcamentaria do projeto no Front-Office.

Documento de detalhamento: [Acompanhamento Orcamentario por Rubrica](US-M003-042-acompanhamento-orcamentario-rubricas.md).

## Criterios de Aceite - US-M003-042

- A visao orcamentaria por rubrica deve aparecer somente para usuario com papel de coordenador da projeto.
- Bolsista, voluntario e demais perfis sem papel de coordenacao nao devem visualizar esse bloco em **Meu Projeto**.
- Exibir uma linha por rubrica com orcamento no projeto.
- Cada linha deve apresentar **Total**, **Consumido**, **Disponivel** e os respectivos percentuais.
- Exibir **Alocado** e percentual de alocacao somente para rubricas que possuam reserva/comprometimento antes do consumo efetivo, como **Bolsa** e **Diarias**.
- Nao exibir **Alocado** para **Material Permanente**, **Material de Consumo**, **Passagens** e **Pessoa Juridica**.
- Ordenar **Diarias** logo abaixo de **Bolsa**.
- A barra de acompanhamento deve refletir consumido, alocado quando existir e saldo disponivel.
