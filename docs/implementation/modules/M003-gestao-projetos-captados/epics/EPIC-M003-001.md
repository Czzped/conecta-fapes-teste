## Contexto

A projeto nasce para o M003 apos a contratacao/outorga. O edital ou chamada de origem pertence ao M011 e pode ser guardado apenas como referencia externa. O M003 passa a ser dono da gestao pos-contratacao da projeto.

## User Stories

### US-M003-001 — Registrar projeto apos contratacao/outorga
Cadastro da projeto com titulo, resumo, datas, valor aprovado, estado inicial e referencias externas de origem.

### US-M003-002 — Classificar projeto por TipoProjeto
Associacao obrigatoria da projeto a um tipo cadastrado, como projeto de pesquisa, projeto de inovacao ou visita tecnica.

### US-M003-003 — Registrar Ortogado da projeto
Vinculo de PessoaFisica do M008 ao papel de `Ortogado`, com data de outorga e indicacao de ativo.
