## Contexto

Durante a avaliacao documental (EPIC-M009-002), o Analista de Bolsas precisa verificar se o pesquisador atende aos requisitos academicos do edital — escolaridade minima, titulacao concluida e historico de formacao. Hoje esse dado esta em sistemas externos (Lattes/M024) e o Analista precisa sair do fluxo para consultar manualmente, gerando retrabalho e atraso.

Este EPIC integra M009 com M024 para exibir, na propria tela de aprovacao, os dados academicos necessarios para a decisao, sem que o Analista precise navegar para outra tela.

## Objetivo

Exibir titulacao maxima, formacoes academicas e flag `curriculoValido` do pesquisador diretamente no painel de aprovacao de bolsa, consumindo a API de M024 de forma read-only.

## Regras de Negocio

- Dados exibidos sao read-only — M009 nao altera dados de M024.
- Se `curriculoValido = false` ou curriculo nao vinculado, exibir aviso com orientacao para o Analista solicitar vinculacao/atualizacao.
- Dados exibidos nao bloqueiam automaticamente a aprovacao — decisao final e do Analista.

## Dependencias

- **Depende de**: EPIC-M009-002, M024 EPIC-M024-002 (formacao academica persistida).
- **Consome**: `GET /api/v1/m024/pesquisadores/{cpf}/curriculo` e `GET /api/v1/m024/pesquisadores/{cpf}/formacao-academica`.

### US-M009-017: Exibir dados academicos na aprovacao de bolsa

Como Analista de Bolsas,
quero ver a formacao academica e titulacao maxima do pesquisador na tela de aprovacao,
para validar elegibilidade sem sair do fluxo.

```gherkin
Funcionalidade: Painel Academico na Aprovacao de Bolsa

  Cenario: Pesquisador com curriculo valido
    Dado que o bolsista indicado possui Curriculo vinculado e valido em M024
    Quando o Analista abre a tela de aprovacao da bolsa
    Entao M009 exibe painel "Perfil Academico" com:
      - titulacaoMaxima (ex: Doutorado)
      - lista de formacoes: {nivel, curso, instituicao, anoConclusao, status}
      - dataUltimaSincronizacao do curriculo
      - flag curriculoValido = true

  Cenario: Pesquisador com curriculo desatualizado
    Dado que o bolsista possui Curriculo com dataUltimaSincronizacao > 12 meses
    Quando o Analista abre a tela de aprovacao
    Entao M009 exibe painel com dados disponiveis
    E exibe aviso "Curriculo desatualizado — ultima sincronizacao: DD/MM/AAAA"
    E orienta o Analista a solicitar atualizacao em M024

  Cenario: Pesquisador sem curriculo vinculado
    Dado que o bolsista nao possui Curriculo vinculado em M024
    Quando o Analista abre a tela de aprovacao
    Entao M009 exibe aviso "Curriculo Lattes nao vinculado"
    E orienta a vincular o curriculo antes da aprovacao

  Cenario: M024 indisponivel
    Dado que M024 retorna erro ao ser consultado
    Quando o Analista abre a tela de aprovacao
    Entao M009 exibe "Dados academicos temporariamente indisponiveis"
    E nao bloqueia o fluxo de aprovacao
```

**Dados exibidos no painel:**

| Campo | Fonte |
|-------|-------|
| Titulacao maxima concluida | M024 `titulacoMaxima` (calculado por US-M024-006) |
| Formacoes (nivel, curso, instituicao, ano, status) | M024 `FormacaoAcademica[]` |
| Data ultima sincronizacao | M024 `Curriculo.dataUltimaSincronizacao` |
| Curriculo valido | M024 `curriculoValido` flag |
