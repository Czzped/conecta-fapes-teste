## Contexto

A agencia de fomento, como orgao publico financiador de pesquisa e inovacao, tem a obrigacao legal de publicar dados abertos sobre seus investimentos em fomento (Art. 3, Art. 5 II, Art. 6). Atualmente, as informacoes publicadas sao limitadas, desatualizadas e exigem compilacao manual. Cidadaos, pesquisadores e orgaos de controle nao possuem acesso facil e padronizado aos dados de projetos financiados, bolsas concedidas e execucao financeira.

Este EPIC e o fundacional do modulo M019: o portal de transparencia e a interface publica que cumpre as exigencias legais de publicidade dos atos administrativos.

## Objetivo

Disponibilizar um portal publico de transparencia com dados abertos sobre projetos, bolsas e programas de fomento da agencia de fomento, com anonimizacao de dados pessoais conforme LGPD e indicadores de transparencia.

### US-M019-001: Publicar Dados Abertos de Fomento

Como Servidor da Area Tecnica,
quero que os dados de fomento sejam publicados automaticamente no portal de transparencia,
para que a agencia de fomento cumpra as exigencias legais de publicidade.

```gherkin
Funcionalidade: Publicar Dados Abertos de Fomento

  Cenario: Publicacao automatica diaria
    Dado que existem dados transacionais atualizados na plataforma
    Quando o processamento diario de transparencia e executado
    Entao o sistema atualiza as publicacoes de projetos, bolsas e execucao financeira no portal
    E os dados pessoais sao anonimizados conforme LGPD (RN02)
    E a data de atualizacao e registrada

  Cenario: Anonimizacao de dados pessoais
    Dado que um projeto possui bolsistas vinculados
    Quando os dados sao publicados no portal de transparencia
    Entao nomes e CPFs dos bolsistas sao substituidos por identificadores anonimos
    E os dados do projeto (titulo, valor, instituicao) permanecem visiveis

  Cenario: Publicacao de execucao financeira
    Dado que existem dados de execucao financeira de programas
    Quando o processamento de transparencia e executado
    Entao o sistema publica valores empenhados, liquidados e pagos por programa
```

### US-M019-002: Consultar Projetos e Bolsas Publicamente

Como Cidadao,
quero consultar projetos financiados e bolsas concedidas pela agencia de fomento,
para que eu possa acompanhar a aplicacao dos recursos publicos.

```gherkin
Funcionalidade: Consultar Projetos e Bolsas Publicamente

  Cenario: Acesso publico sem autenticacao
    Dado que o portal de transparencia esta disponivel
    Quando um cidadao acessa a pagina de consulta
    Entao o sistema exibe os dados sem exigir login ou autenticacao (RN07)

  Cenario: Consulta de projetos financiados
    Dado que existem projetos publicados no portal
    Quando o cidadao pesquisa por "inteligencia artificial"
    Entao o sistema exibe os projetos cujo titulo ou descricao contem o termo pesquisado
    E exibe edital, instituicao, valor e status de cada projeto

  Cenario: Consulta de bolsas concedidas
    Dado que existem bolsas publicadas no portal
    Quando o cidadao filtra por modalidade e periodo
    Entao o sistema exibe a quantidade de bolsas, valor total e distribuicao por instituicao
    E nao exibe dados pessoais dos bolsistas (RN02)

  Cenario: Filtro por programa e edital
    Dado que o cidadao esta na pagina de consulta
    Quando seleciona o programa e o edital desejados
    Entao o sistema exibe apenas os dados do escopo selecionado
```

### US-M019-003: Dashboard de Indicadores de Transparencia

Como Gestor da agencia de fomento,
quero visualizar indicadores de transparencia da plataforma,
para que eu possa monitorar a completude e a atualizacao dos dados publicados.

```gherkin
Funcionalidade: Dashboard de Indicadores de Transparencia

  Cenario: Visualizacao de indicadores de transparencia
    Dado que o Gestor esta autenticado
    Quando acessa o dashboard de indicadores de transparencia
    Entao o sistema exibe volume de dados publicados, frequencia de atualizacao e cobertura por tipo de dado

  Cenario: Calculo automatico de indicadores
    Dado que o processamento diario de transparencia foi executado
    Quando o sistema calcula os indicadores de transparencia (RN08)
    Entao os valores de volume publicado, percentual de cobertura e atraso medio sao atualizados

  Cenario: Alerta de dados desatualizados
    Dado que existem publicacoes com mais de 48 horas sem atualizacao
    Quando o Gestor acessa o dashboard
    Entao o sistema destaca as publicacoes desatualizadas com alerta visual
```
