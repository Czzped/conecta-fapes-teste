## Contexto

Durante a execucao de um projeto, situacoes imprevistas podem exigir recursos adicionais alem do orcamento originalmente aprovado. Atualmente, coordenadores solicitam adicoes orcamentarias por e-mail ou oficio em papel, sem padronizacao e sem rastreabilidade do fluxo de aprovacao. A Area Tecnica nao possui visibilidade consolidada das solicitacoes pendentes, e os coordenadores nao sabem o status de suas solicitacoes.

Sem um fluxo digital estruturado, solicitacoes se perdem, aprovacoes atrasam e nao ha registro auditavel das decisoes.

Este EPIC e o ponto de entrada do modulo M013: sem o mecanismo de solicitacao e aprovacao, as demais operacoes orcamentarias nao podem ser formalizadas.

## Objetivo

Permitir que coordenadores solicitem adicoes orcamentarias, que a Area Tecnica analise as solicitacoes e que a aprovacao seja registrada de forma rastreavel, atualizando automaticamente o orcamento do projeto.

### US-M013-001: Solicitar Adicao Orcamentaria

Como Coordenador do Projeto,
quero solicitar uma adicao orcamentaria informando valor e justificativa,
para que recursos adicionais sejam alocados ao meu projeto.

```gherkin
Funcionalidade: Solicitar Adicao Orcamentaria

  Cenario: Criacao de solicitacao com dados validos
    Dado que o Coordenador esta autenticado
    E o projeto esta com status "Ativo"
    Quando informa o valor solicitado e a justificativa
    E confirma a criacao
    Entao o sistema salva a solicitacao com status "Rascunho"

  Cenario: Submissao de solicitacao
    Dado que existe uma solicitacao em "Rascunho"
    Quando o Coordenador revisa os dados e confirma a submissao
    Entao o sistema altera o status para "Submetida"
    E notifica a Area Tecnica sobre a nova solicitacao

  Cenario: Tentativa de solicitar adicao para projeto inativo
    Dado que o projeto nao esta com status "Ativo"
    Quando o Coordenador tenta criar uma solicitacao de adicao
    Entao o sistema impede a criacao
    E exibe mensagem informando que o projeto nao esta ativo (RI1)

  Cenario: Submissao sem justificativa
    Dado que existe uma solicitacao em "Rascunho" sem justificativa preenchida
    Quando o Coordenador tenta submeter
    Entao o sistema impede a submissao
    E exibe mensagem indicando que a justificativa e obrigatoria (RN04)
```

### US-M013-002: Analisar Solicitacao de Adicao

Como Servidor da Area Tecnica,
quero analisar uma solicitacao de adicao orcamentaria,
para que eu possa emitir parecer favoravel ou desfavoravel com justificativa.

```gherkin
Funcionalidade: Analisar Solicitacao de Adicao

  Cenario: Inicio da analise
    Dado que existe uma solicitacao com status "Submetida"
    Quando o Servidor da Area Tecnica abre a solicitacao para analise
    Entao o sistema altera o status para "Em Analise"

  Cenario: Emissao de parecer favoravel
    Dado que a solicitacao esta com status "Em Analise"
    Quando o Servidor emite parecer favoravel com justificativa
    Entao o sistema registra o parecer
    E altera o status para "Aprovada"
    E notifica o Coordenador sobre a aprovacao

  Cenario: Emissao de parecer desfavoravel
    Dado que a solicitacao esta com status "Em Analise"
    Quando o Servidor emite parecer desfavoravel com justificativa
    Entao o sistema registra o parecer
    E altera o status para "Rejeitada"
    E notifica o Coordenador sobre a rejeicao com a justificativa
```

### US-M013-003: Registrar Aprovacao de Adicao

Como Servidor da Area Tecnica,
quero que a aprovacao de uma adicao orcamentaria atualize automaticamente o orcamento do projeto,
para que o saldo reflita os novos recursos disponiveis.

```gherkin
Funcionalidade: Registrar Aprovacao de Adicao

  Cenario: Atualizacao do orcamento apos aprovacao
    Dado que uma solicitacao de adicao foi aprovada com valor de R$ 50.000,00
    Quando o sistema processa a aprovacao
    Entao o valor aprovado e adicionado ao orcamento total do projeto
    E o historico orcamentario registra a movimentacao com tipo "Adicao" (RN05)

  Cenario: Aprovacao que excede limite do edital
    Dado que o edital define um limite maximo de R$ 500.000,00 por projeto
    E o projeto ja possui R$ 480.000,00 aprovados
    Quando uma adicao de R$ 30.000,00 e aprovada
    Entao o sistema exibe alerta informando que o valor excede o limite do edital (RI2)
    E registra a ressalva no historico
```
