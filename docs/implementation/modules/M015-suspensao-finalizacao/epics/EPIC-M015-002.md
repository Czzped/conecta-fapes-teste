## Contexto

O encerramento definitivo de um projeto e uma operacao critica que exige a verificacao de multiplas pendencias: todas as prestacoes de contas devem estar aprovadas, todas as bolsas ativas devem estar encerradas e nao podem existir pagamentos pendentes. Atualmente, nao ha um checklist automatizado -- a verificacao e feita manualmente pela Area Tecnica, consultando diferentes sistemas e planilhas. Isso gera encerramentos incompletos e projetos que ficam abertos indefinidamente por falta de resolucao de pendencias.

Sem um fluxo digital de finalizacao, projetos concluidos ha anos continuam registrados como ativos, distorcendo relatorios e indicadores da agencia de fomento.

## Objetivo

Permitir a solicitacao de encerramento de projetos, a verificacao automatica de pendencias (prestacoes de contas, bolsas, pagamentos) e o encerramento definitivo e irreversivel quando todas as pendencias estiverem resolvidas.

### US-M015-004: Solicitar Encerramento

Como Coordenador do Projeto ou Servidor da Area Tecnica,
quero solicitar o encerramento definitivo de um projeto informando o motivo,
para que o fluxo de verificacao de pendencias seja iniciado.

```gherkin
Funcionalidade: Solicitar Encerramento

  Cenario: Solicitacao por conclusao natural
    Dado que o Coordenador esta autenticado
    E o projeto esta com status "Ativo" ou "Suspenso"
    Quando seleciona o motivo "Conclusao Natural"
    E informa a justificativa
    E confirma a solicitacao
    Entao o sistema registra a solicitacao com status "Submetida"
    E altera o status do projeto para "Em Encerramento"
    E inicia a verificacao automatica de pendencias
    E registra no historico (RN07)

  Cenario: Solicitacao por decisao do coordenador
    Dado que o Coordenador esta autenticado
    E o projeto esta com status "Ativo"
    Quando seleciona o motivo "Decisao Coordenador"
    E informa a justificativa
    E confirma a solicitacao
    Entao o sistema registra a solicitacao com status "Submetida"
    E altera o status do projeto para "Em Encerramento"

  Cenario: Solicitacao por determinacao da agencia de fomento
    Dado que o Servidor da Area Tecnica esta autenticado
    Quando seleciona o motivo "Determinacao agencia de fomento"
    E informa a justificativa
    E confirma a solicitacao
    Entao o sistema registra a solicitacao com status "Submetida"
    E altera o status do projeto para "Em Encerramento"
    E notifica o Coordenador

  Cenario: Tentativa de encerrar projeto ja encerrado
    Dado que o projeto esta com status "Encerrado"
    Quando o usuario tenta solicitar encerramento
    Entao o sistema impede a solicitacao
    E exibe mensagem informando que o projeto ja esta encerrado (RN06)
```

### US-M015-005: Verificar Pendencias

Como Servidor da Area Tecnica,
quero que o sistema verifique automaticamente todas as pendencias do projeto,
para que eu saiba exatamente o que precisa ser resolvido antes do encerramento.

```gherkin
Funcionalidade: Verificar Pendencias

  Cenario: Projeto sem pendencias
    Dado que o projeto esta com status "Em Encerramento"
    Quando o sistema executa a verificacao de pendencias
    E nao encontra bolsas ativas (M009)
    E nao encontra prestacoes de contas pendentes (M014)
    E nao encontra pagamentos pendentes (M004)
    Entao o sistema altera o status da solicitacao para "Pendencias Resolvidas"
    E habilita a confirmacao do encerramento

  Cenario: Projeto com bolsas ativas
    Dado que o projeto esta com status "Em Encerramento"
    Quando o sistema executa a verificacao de pendencias
    E encontra 2 bolsas com status "Implementada"
    Entao o sistema registra as pendencias do tipo "Bolsa Ativa"
    E altera o status para "Pendencias Pendentes"
    E exibe a lista de bolsas que precisam ser encerradas (RN05)

  Cenario: Projeto com prestacao de contas pendente
    Dado que o projeto esta com status "Em Encerramento"
    Quando o sistema executa a verificacao de pendencias
    E encontra prestacoes de contas nao submetidas ou nao aprovadas
    Entao o sistema registra as pendencias do tipo "Prestacao de Contas Pendente"
    E altera o status para "Pendencias Pendentes"
    E exibe as prestacoes que precisam ser resolvidas (RN04)

  Cenario: Reverificacao apos resolucao parcial
    Dado que o projeto estava com pendencias de bolsas e prestacao de contas
    E as bolsas foram encerradas via M009
    Quando o Servidor solicita nova verificacao
    Entao o sistema reavalia as pendencias
    E atualiza o status das pendencias resolvidas
    E exibe as pendencias ainda existentes
```

### US-M015-006: Encerrar Projeto

Como Servidor da Area Tecnica,
quero encerrar definitivamente um projeto apos todas as pendencias terem sido resolvidas,
para que o projeto seja finalizado de forma irreversivel e o registro reflita a conclusao.

```gherkin
Funcionalidade: Encerrar Projeto

  Cenario: Encerramento com sucesso
    Dado que o projeto esta com status "Em Encerramento"
    E a solicitacao esta com status "Pendencias Resolvidas"
    Quando o Servidor da Area Tecnica confirma o encerramento
    Entao o sistema altera o status do projeto para "Encerrado"
    E altera o status da solicitacao para "Encerrada"
    E registra a data de encerramento definitivo
    E notifica o Coordenador sobre o encerramento
    E registra no historico (RN07)

  Cenario: Tentativa de encerrar com pendencias
    Dado que o projeto esta com status "Em Encerramento"
    E a solicitacao esta com status "Pendencias Pendentes"
    Quando o Servidor tenta confirmar o encerramento
    Entao o sistema impede o encerramento
    E exibe a lista de pendencias que precisam ser resolvidas

  Cenario: Irreversibilidade do encerramento
    Dado que o projeto foi encerrado com sucesso
    Quando qualquer usuario tenta realizar qualquer operacao no projeto
    Entao o sistema impede a operacao
    E exibe mensagem informando que o projeto esta encerrado e nao permite alteracoes (RN06)

  Cenario: Encerramento de projeto suspenso
    Dado que o projeto esta com status "Suspenso"
    E uma solicitacao de encerramento foi registrada
    E todas as pendencias foram resolvidas
    Quando o Servidor confirma o encerramento
    Entao o sistema altera o status do projeto de "Suspenso" para "Encerrado"
    E registra no historico que o encerramento ocorreu a partir da suspensao
```
