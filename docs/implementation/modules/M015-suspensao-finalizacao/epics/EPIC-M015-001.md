## Contexto

Projetos em execucao podem necessitar de suspensao temporaria por diversos motivos: licenca do coordenador, forca maior, irregularidades identificadas pela agencia de fomento ou necessidade de replanejamento. Atualmente, a comunicacao de suspensao e feita informalmente, e nao ha mecanismo que bloqueie automaticamente pagamentos e novas alocacoes de bolsas. Isso gera situacoes em que pagamentos continuam sendo processados para projetos que deveriam estar suspensos, ou bolsistas sao alocados em projetos sem atividade.

Sem um fluxo digital, a reativacao tambem e informal, sem registro de quem autorizou e quando o projeto retornou a operacao normal.

Este EPIC e o primeiro do modulo M015: a suspensao e prerequisito para que o fluxo de finalizacao possa considerar projetos suspensos.

## Objetivo

Permitir a solicitacao de suspensao de projetos (pelo coordenador ou pela agencia de fomento), a analise pela Area Tecnica, o bloqueio automatico de pagamentos e bolsas, e a reativacao controlada com aprovacao.

### US-M015-001: Solicitar Suspensao

Como Coordenador do Projeto ou Servidor da Area Tecnica,
quero solicitar a suspensao temporaria de um projeto informando a justificativa,
para que pagamentos e novas alocacoes sejam bloqueados ate a resolucao do motivo.

```gherkin
Funcionalidade: Solicitar Suspensao

  Cenario: Solicitacao pelo coordenador com dados validos
    Dado que o Coordenador esta autenticado
    E o projeto esta com status "Ativo"
    Quando informa a justificativa para suspensao
    E confirma a solicitacao
    Entao o sistema registra a solicitacao com origem "Coordenador" e status "Submetida"
    E notifica a Area Tecnica sobre a solicitacao de suspensao
    E registra no historico (RN07)

  Cenario: Solicitacao pela agencia de fomento
    Dado que o Servidor da Area Tecnica esta autenticado
    E o projeto esta com status "Ativo"
    Quando informa a justificativa para suspensao determinada pela agencia de fomento
    E confirma a solicitacao
    Entao o sistema registra a solicitacao com origem "agencia de fomento" e status "Submetida"
    E registra no historico (RN07)

  Cenario: Tentativa de suspender projeto ja suspenso
    Dado que o projeto esta com status "Suspenso"
    Quando o usuario tenta solicitar nova suspensao
    Entao o sistema impede a solicitacao
    E exibe mensagem informando que o projeto ja esta suspenso (RI1)

  Cenario: Tentativa de suspender projeto em encerramento
    Dado que o projeto esta com status "Em Encerramento"
    Quando o usuario tenta solicitar suspensao
    Entao o sistema impede a solicitacao
    E exibe mensagem informando que o projeto esta em processo de encerramento (RI2)

  Cenario: Solicitacao sem justificativa
    Dado que o usuario esta na tela de solicitacao de suspensao
    Quando tenta submeter sem informar justificativa
    Entao o sistema impede a submissao
    E exibe mensagem informando que a justificativa e obrigatoria (RN01)
```

### US-M015-002: Analisar Suspensao

Como Servidor da Area Tecnica,
quero analisar uma solicitacao de suspensao e emitir parecer,
para que a suspensao seja efetivada ou rejeitada de forma rastreavel.

```gherkin
Funcionalidade: Analisar Suspensao

  Cenario: Inicio da analise
    Dado que existe uma solicitacao de suspensao com status "Submetida"
    Quando o Servidor da Area Tecnica abre a solicitacao para analise
    Entao o sistema altera o status para "Em Analise"

  Cenario: Aprovacao da suspensao
    Dado que a solicitacao esta com status "Em Analise"
    Quando o Servidor emite parecer favoravel com justificativa
    Entao o sistema altera o status da solicitacao para "Aprovada"
    E altera o status do projeto para "Suspenso"
    E bloqueia todos os pagamentos do projeto (RN02)
    E bloqueia a alocacao de novas bolsas no projeto (RN02)
    E notifica o Coordenador sobre a suspensao efetivada
    E registra no historico (RN07)

  Cenario: Rejeicao da suspensao
    Dado que a solicitacao esta com status "Em Analise"
    Quando o Servidor emite parecer desfavoravel com justificativa
    Entao o sistema altera o status da solicitacao para "Rejeitada"
    E o projeto permanece com status "Ativo"
    E notifica o Coordenador sobre a rejeicao com justificativa
    E registra no historico (RN07)
```

### US-M015-003: Reativar Projeto

Como Servidor da Area Tecnica,
quero reativar um projeto suspenso,
para que o projeto retorne a operacao normal com pagamentos e bolsas habilitados.

```gherkin
Funcionalidade: Reativar Projeto

  Cenario: Reativacao com sucesso
    Dado que o projeto esta com status "Suspenso"
    Quando o Servidor da Area Tecnica aprova a reativacao informando justificativa
    Entao o sistema altera o status do projeto para "Ativo"
    E desbloqueia os pagamentos do projeto
    E permite novamente a alocacao de novas bolsas
    E notifica o Coordenador sobre a reativacao
    E registra no historico (RN07)

  Cenario: Tentativa de reativacao sem aprovacao da Area Tecnica
    Dado que o projeto esta com status "Suspenso"
    Quando o Coordenador tenta solicitar reativacao
    Entao o sistema registra a solicitacao
    E notifica a Area Tecnica que a reativacao depende de aprovacao (RN03)

  Cenario: Reativacao de projeto com justificativa de irregularidade
    Dado que o projeto foi suspenso por irregularidade identificada pela agencia de fomento
    Quando o Servidor da Area Tecnica analisa a solicitacao de reativacao
    Entao o sistema exibe o motivo original da suspensao
    E exige que o Servidor confirme que a irregularidade foi sanada
```
