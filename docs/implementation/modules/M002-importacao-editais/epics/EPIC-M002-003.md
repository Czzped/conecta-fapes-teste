## Contexto

Apos a planilha corrigida, o proximo passo do pipeline e transformar os dados validados em arquivos JSONL consumidos por M003 (Iniciativas Captadas) e por M008/M009 conforme a entidade. A geracao deve respeitar o tipo ativo (`editais` ou `programas`), usar o mapeamento de programas configurado e produzir arquivos versionados por competencia.

## Objetivo

Gerar, sob demanda, os arquivos JSONL de importacao (`editais.jsonl`, `projetos.jsonl`, `pessoas.jsonl`, `alocacoes.jsonl`, etc.) a partir da planilha ativa, com acompanhamento assincrono via `import_jobs` para suportar editais volumosos.

### US-M002-012: Iniciar Geracao de JSONL

```gherkin
Funcionalidade: Iniciar geracao

  Cenario: Geracao valida
    Dado que existe planilha com versao >= 1 para o escopo
    E que o operador possui lock ativo
    E que o mapeamento de programas esta completo
    Quando o operador clica em "Gerar arquivos de importacao"
    Entao o backend cria import_jobs com status=pending
    E retorna 202 com o job_id

  Cenario: Geracao sem lock
    Dado que o operador nao possui lock ativo sobre o recurso
    Quando tenta iniciar a geracao
    Entao o backend recusa com 409
```

---

### US-M002-013: Acompanhar Progresso do Job

```gherkin
Funcionalidade: Polling de job

  Cenario: Job em execucao
    Dado que existe import_jobs com status=running
    Quando o frontend consulta GET /jobs/{id}
    Entao o backend retorna status, attempts e started_at

  Cenario: Job concluido
    Dado que o worker terminou a producao dos JSONLs
    Quando o frontend consulta GET /jobs/{id}
    Entao o backend retorna status=completed e lista de chaves S3 produzidas

  Cenario: Job com falha
    Dado que o worker encontrou erro irrecuperavel
    Quando attempts >= limite
    Entao status vira failed com campo error preenchido
    E o frontend exibe mensagem acionavel ao operador
```

---

### US-M002-014: Bloquear Geracao com Mapeamento Incompleto

```gherkin
Funcionalidade: Validacao de mapeamento

  Cenario: Projetos sem Area Tecnica
    Dado que dados-programas.json nao mapeia um ou mais projetos do edital
    Quando o operador tenta iniciar a geracao
    Entao o backend retorna 422 com lista dos projeto_id faltantes
    E o frontend abre ProgramConfigModal destacando as linhas pendentes
```

---

### US-M002-015: Listar Versoes e Arquivos Produzidos

```gherkin
Funcionalidade: Historico de versoes e arquivos

  Cenario: Listar versoes da planilha
    Quando o operador acessa o painel de historico
    Entao o backend retorna planilha_version_audit ordenado por created_at desc
    E exibe version, actor_email, action e s3_key

  Cenario: Listar JSONLs de uma competencia
    Dado que existem jobs concluidos para o edital na competencia atual
    Quando o operador abre a aba "Arquivos gerados"
    Entao o sistema lista cada entidade com chave S3, tamanho e instante de geracao
```
