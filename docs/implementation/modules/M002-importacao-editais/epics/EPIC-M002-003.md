## Contexto

Os dados no SigFapes sao continuamente atualizados — novos projetos sao aprovados, novas alocacoes sao criadas, bolsistas mudam de situacao. Se o ConectaFapes nao refletir essas alteracoes, as folhas de pagamento serao geradas com dados defasados, causando pagamentos incorretos ou a ausencia de pagamentos devidos. Este EPIC garante que os dados do ConectaFapes estejam sempre atualizados antes de qualquer operacao critica.

## Objetivo

Manter os dados de Editais, Projetos, Alocacoes e Bolsistas sincronizados entre SigFapes e ConectaFapes, importando novos registros e atualizando os existentes, gerando relatorio das ocorrencias relevantes.

### US-M002-010: Sincronizar Dados do SigFapes

Como Gerente da Area Tecnica,
quero que os dados de editais, projetos, alocacoes e bolsistas sejam sincronizados com o SigFapes,
para que o ConectaFapes reflita o estado atual dos dados antes de qualquer acao critica.

```gherkin
Funcionalidade: Sincronizar Dados do SigFapes

  Cenario: Sincronizacao com atualizacao de dados existentes
    Dado que existem editais com status "importado"
    Quando o sistema executa a sincronizacao
    Entao o sistema atualiza os dados de Projetos, Alocacoes e Bolsistas ja existentes na base (RNF03)
    E a sincronizacao e concluida em menos de 5 segundos (RNF01)

  Cenario: Sincronizacao com novos registros
    Dado que novos projetos foram cadastrados no SigFapes para um edital ja importado
    Quando o sistema executa a sincronizacao
    Entao o sistema importa os novos Projetos, Alocacoes e Bolsistas
    E os novos projetos ficam com status de preenchimento "Incompleto"

  Cenario: Sincronizacao com novos editais
    Dado que novos editais foram disponibilizados no SigFapes
    Quando o sistema executa a sincronizacao
    Entao o sistema importa os novos editais para a lista de editais disponiveis

  Cenario: Falha na comunicacao com SigFapes
    Dado que o Web Service do SigFapes esta indisponivel (RNF02)
    Quando o sistema tenta sincronizar
    Entao o sistema registra o erro
    E notifica o usuario sobre a falha
```

### US-M002-011: Gerar Relatorio de Sincronizacao

Como Gerente da Area Tecnica,
quero visualizar um relatorio das ocorrencias apos cada sincronizacao,
para que eu possa identificar alteracoes relevantes nos dados importados.

```gherkin
Funcionalidade: Gerar Relatorio de Sincronizacao

  Cenario: Relatorio com ocorrencias
    Dado que a sincronizacao foi executada com sucesso
    Quando o sistema finaliza a sincronizacao
    Entao o sistema gera um relatorio listando novos editais, novos projetos, novas alocacoes, novos bolsistas e dados atualizados

  Cenario: Relatorio sem alteracoes
    Dado que a sincronizacao foi executada e nenhum dado foi alterado
    Quando o sistema finaliza a sincronizacao
    Entao o sistema gera um relatorio informando que nao houve alteracoes
```
