## Contexto

Os dados importados do SigFapes nao contem informacoes como a quantidade de cotas ja pagas ou o detalhamento de alocacoes canceladas — esses dados sao controlados manualmente via planilhas. Sem a complementacao dessas informacoes, os projetos nao podem ser considerados pelo modulo de pagamento. Este EPIC resolve o problema ao permitir que o Gerente da Area Tecnica preencha as informacoes faltantes diretamente no ConectaFapes.

## Objetivo

Permitir que o Gerente da Area Tecnica visualize as alocacoes de cada projeto importado e complete as informacoes de cotas pagas e cancelamentos, para que o projeto atinja o status "Completo" e possa ser processado pelo modulo de pagamento.

### US-M002-005: Consultar Resumo do Edital

Como Gerente da Area Tecnica,
quero consultar o resumo de um edital importado,
para que eu possa acompanhar o progresso da complementacao de dados.

```gherkin
Funcionalidade: Consultar Resumo do Edital

  Cenario: Exibicao do resumo do edital
    Dado que o edital "001/2023" esta com status "importado"
    Quando o Gerente da Area Tecnica seleciona o edital
    Entao o sistema exibe nome, area tecnica, data e hora da ultima sincronizacao, quantidade de projetos, quantidade de projetos completos, quantidade de alocacoes e quantidade de alocacoes completas
```

### US-M002-006: Visualizar Projetos e Alocacoes

Como Gerente da Area Tecnica,
quero visualizar os projetos de um edital e as alocacoes de cada projeto,
para que eu possa identificar quais alocacoes precisam de complementacao.

```gherkin
Funcionalidade: Visualizar Projetos e Alocacoes

  Cenario: Listagem de projetos do edital
    Dado que o Gerente da Area Tecnica selecionou o edital "001/2023"
    Quando o sistema exibe os projetos
    Entao cada projeto mostra nome, status e status de preenchimento ("Incompleto" ou "Completo")

  Cenario: Listagem de alocacoes do projeto
    Dado que o Gerente da Area Tecnica selecionou um projeto
    Quando o sistema exibe as alocacoes
    Entao cada alocacao mostra nome do bolsista, quantidade de cotas pagas, quantidade total de cotas e status da alocacao
    E caso a alocacao esteja "cancelada", exibe tambem a data de fim das atividades
```

### US-M002-007: Informar Cotas Pagas da Alocacao

Como Gerente da Area Tecnica,
quero informar ou alterar a quantidade de cotas pagas de uma alocacao,
para que a informacao de pagamento reflita os dados reais das planilhas.

```gherkin
Funcionalidade: Informar Cotas Pagas da Alocacao

  Cenario: Informar cotas pagas com sucesso
    Dado que a alocacao do bolsista "Joao Silva" esta com status diferente de "pendente"
    Quando o Gerente da Area Tecnica informa a quantidade de cotas pagas como 6
    E confirma
    Entao o sistema salva a quantidade de cotas pagas

  Cenario: Alterar cotas pagas
    Dado que a alocacao do bolsista "Joao Silva" ja possui cotas pagas informadas como 6
    Quando o Gerente da Area Tecnica altera para 8
    E confirma
    Entao o sistema salva a nova quantidade de cotas pagas

  Cenario: Tentativa de retornar cotas pagas para nulo
    Dado que a alocacao do bolsista "Joao Silva" ja possui cotas pagas informadas
    Quando o Gerente da Area Tecnica tenta limpar o campo de cotas pagas
    Entao o sistema impede a acao (RN01)
    E exibe mensagem informando que cotas pagas nao podem retornar para nulo

  Cenario: Tentativa de informar cotas em alocacao pendente
    Dado que a alocacao do bolsista "Maria Santos" esta com status "pendente"
    Quando o Gerente da Area Tecnica tenta informar cotas pagas
    Entao o sistema impede a acao
```

### US-M002-008: Cancelar Alocacao

Como Gerente da Area Tecnica,
quero cancelar uma alocacao informando data de fim de atividades e justificativa,
para que alocacoes encerradas prematuramente sejam registradas corretamente.

```gherkin
Funcionalidade: Cancelar Alocacao

  Cenario: Cancelamento com dados obrigatorios
    Dado que a alocacao do bolsista "Joao Silva" esta ativa
    Quando o Gerente da Area Tecnica informa a data de fim de atividades e a justificativa
    E confirma o cancelamento
    Entao o sistema salva a alocacao com status "cancelada" (RN02)

  Cenario: Cancelamento sem data de fim de atividades
    Dado que a alocacao do bolsista "Joao Silva" esta ativa
    Quando o Gerente da Area Tecnica tenta cancelar sem informar a data de fim de atividades
    Entao o sistema exibe mensagem de validacao informando que a data de fim e obrigatoria (RN02)

  Cenario: Cancelamento sem justificativa
    Dado que a alocacao do bolsista "Joao Silva" esta ativa
    Quando o Gerente da Area Tecnica tenta cancelar sem informar a justificativa
    Entao o sistema exibe mensagem de validacao informando que a justificativa e obrigatoria (RN02)

  Cenario: Alocacao cancelada vinda do SigFapes
    Dado que a alocacao do bolsista "Pedro Souza" veio do SigFapes com status "cancelada"
    Quando o sistema importa a alocacao
    Entao a alocacao e salva sem exigir data de fim de atividades ou justificativa (RN02)
```

### US-M002-009: Marcar Projeto como Completo

Como Gerente da Area Tecnica,
quero que o projeto seja automaticamente marcado como "Completo" quando todas as alocacoes estiverem preenchidas,
para que o projeto possa ser processado pelo modulo de pagamento.

```gherkin
Funcionalidade: Marcar Projeto como Completo

  Cenario: Projeto completo automaticamente
    Dado que o projeto "PROJ-001" possui 3 alocacoes
    E todas as alocacoes possuem cotas pagas informadas e dados de cancelamento preenchidos quando aplicavel
    Quando o sistema verifica o preenchimento
    Entao o status de preenchimento do projeto e alterado para "Completo" (RN04)

  Cenario: Projeto incompleto
    Dado que o projeto "PROJ-001" possui 3 alocacoes
    E uma alocacao ainda nao possui cotas pagas informadas
    Quando o sistema verifica o preenchimento
    Entao o status de preenchimento do projeto permanece "Incompleto"

  Cenario: Projeto com substituicao de coordenador
    Dado que existem dois projetos no SigFapes referentes ao mesmo projeto com mudanca de coordenador
    Quando o sistema importa os dados
    Entao o sistema adapta para contar como um unico projeto (RN03)
```
