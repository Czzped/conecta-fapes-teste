# EPIC-M002-001: Definir Editais a Sincronizar

[← Voltar ao Sub-Backlog](../backlog.md)

## Contexto

Antes de importar projetos, alocacoes e bolsistas, e necessario que o Gerente da Area Tecnica defina quais editais do SigFapes serao gerenciados no ConectaFapes. Sem essa selecao, o sistema nao sabe quais editais devem ter seus dados importados e sincronizados. Este EPIC e o ponto de partida do modulo — nenhuma importacao ou complementacao de dados ocorre sem que os editais tenham sido previamente selecionados.

## Objetivo

Permitir que o Gerente da Area Tecnica selecione editais do SigFapes para importacao, associe cada edital a uma Area Tecnica, e dispare a importacao de Projetos, Alocacoes e Bolsistas para o ConectaFapes.

## Regras de Negocio

RN05, RN06, RN07, RN08 — ver [Regras de Negocio](../README.md#regras-de-negocio)

- **Habilita**: EPIC-M002-002 (Completar Dados de Alocacoes), EPIC-M002-003 (Sincronizar Dados de Editais)

### US-M002-001: Listar Editais Disponiveis no SigFapes

Como Gerente da Area Tecnica,
quero visualizar a lista de editais disponiveis no SigFapes,
para que eu possa identificar quais editais desejo importar para o ConectaFapes.

```gherkin
Funcionalidade: Listar Editais Disponiveis no SigFapes

  Cenario: Listagem de editais do SigFapes
    Dado que a carga inicial foi realizada
    Quando o Gerente da Area Tecnica acessa a tela de selecao de editais
    Entao o sistema exibe uma lista de editais do SigFapes contendo nome e data de criacao

  Cenario: Nenhum edital disponivel
    Dado que a carga inicial nao trouxe editais
    Quando o Gerente da Area Tecnica acessa a tela de selecao de editais
    Entao o sistema exibe mensagem informando que nao ha editais disponiveis
```

---

### US-M002-002: Selecionar Editais para Importacao

Como Gerente da Area Tecnica,
quero selecionar editais do SigFapes e associa-los a uma Area Tecnica,
para que seus projetos, alocacoes e bolsistas sejam importados para o ConectaFapes.

```gherkin
Funcionalidade: Selecionar Editais para Importacao

  Cenario: Selecao de editais com area tecnica
    Dado que o Gerente da Area Tecnica esta na lista de editais do SigFapes
    Quando seleciona um ou mais editais
    E informa a Area Tecnica ao qual os editais estao relacionados
    E confirma a selecao
    Entao o sistema salva cada edital com a area tecnica informada e status "a importar"
    E acrescenta os editais a lista de editais a sincronizar (RN05, RN06)

  Cenario: Selecao sem informar area tecnica
    Dado que o Gerente da Area Tecnica selecionou editais
    Quando tenta confirmar sem informar a Area Tecnica
    Entao o sistema exibe mensagem de validacao indicando que a Area Tecnica e obrigatoria
```

### US-M002-003: Importar Dados dos Editais Selecionados

Como Gerente da Area Tecnica,
quero que o sistema importe automaticamente os Projetos, Alocacoes e Bolsistas dos editais selecionados,
para que os dados estejam disponiveis no ConectaFapes para complementacao e pagamento.

```gherkin
Funcionalidade: Importar Dados dos Editais Selecionados

  Cenario: Importacao bem-sucedida
    Dado que existem editais com status "a importar"
    Quando o sistema executa a importacao
    Entao o sistema importa Projetos, Alocacoes e Bolsistas de cada edital
    E cada edital recebe o status "importado" (RN07)
    E os dados ficam disponiveis para complementacao

  Cenario: Falha na importacao
    Dado que existem editais com status "a importar"
    Quando o sistema nao consegue acessar o SigFapes
    Entao o sistema registra o erro
    E o edital permanece com status "a importar"
```

### US-M002-004: Listar Editais a Sincronizar

Como Gerente da Area Tecnica,
quero visualizar a lista de editais ja importados com suas informacoes de acompanhamento,
para que eu possa monitorar o progresso da complementacao de dados.

```gherkin
Funcionalidade: Listar Editais a Sincronizar

  Cenario: Listagem de editais importados
    Dado que existem editais com status "importado"
    Quando o Gerente da Area Tecnica acessa a lista de editais a sincronizar
    Entao o sistema exibe de cada edital o nome, area tecnica, status de importacao, data e hora da ultima sincronizacao, quantidade de projetos completos e quantidade total de projetos

  Cenario: Filtro por area tecnica
    Dado que existem editais importados de diferentes areas tecnicas
    Quando o Gerente da Area Tecnica filtra por uma area tecnica especifica
    Entao o sistema exibe apenas os editais da area tecnica selecionada
```
