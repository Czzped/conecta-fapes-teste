## Contexto

Cada `JustificativaDespesa` pode ter ate tres orcamentos de fornecedor (`OrcamentoFornecedor`) para comprovacao de pesquisa de preco. Um dos orcamentos deve ser selecionado como vencedor (`Escolhido = true`). Os PDFs dos orcamentos sao armazenados no MinIO com URL pre-assinada.

## Objetivo

Permitir que coordenadores cadastrem em lote ate tres orcamentos por justificativa, faca upload dos PDFs, selecionem o vencedor e consultem ou editem os orcamentos existentes.

### US-M014-022: Criar Orcamentos em Lote

Como Coordenador do Projeto,
quero cadastrar em lote ate tres orcamentos de fornecedor para uma justificativa,
para demonstrar pesquisa de preco na contratacao dos servicos.

```gherkin
Funcionalidade: Criar Orcamentos em Lote

  Cenario: Criar tres orcamentos validos
    Dado que a JustificativaDespesa existe e a Prestacao esta com status "RASCUNHO"
    Quando o Coordenador submete lista com ate 3 OrcamentoFornecedor (fornecedor, valor, descricao)
    Entao o sistema persiste os OrcamentoFornecedor vinculados a JustificativaDespesa

  Cenario: Tentativa de criar mais de tres orcamentos
    Dado que a JustificativaDespesa ja possui 3 OrcamentoFornecedor
    Quando o Coordenador tenta adicionar mais um orcamento
    Entao o sistema impede o cadastro
    E exibe mensagem informando que o limite de 3 orcamentos por justificativa foi atingido

  Cenario: Criar orcamento com dados minimos
    Dado que a Prestacao esta com status "RASCUNHO"
    Quando o Coordenador submete 1 orcamento com fornecedor e valor
    Entao o sistema persiste o OrcamentoFornecedor sem exigir upload imediato de PDF
```

### US-M014-023: Upload de PDF do Orcamento

Como Coordenador do Projeto,
quero fazer upload do PDF de um orcamento de fornecedor,
para anexar a documentacao fisica da pesquisa de preco.

```gherkin
Funcionalidade: Upload de PDF do Orcamento

  Cenario: Upload de PDF com sucesso
    Dado que o OrcamentoFornecedor existe sem arquivo PDF
    Quando o Coordenador faz upload de arquivo PDF
    Entao o sistema armazena o arquivo no MinIO
    E persiste URL pre-assinada no OrcamentoFornecedor

  Cenario: Upload de arquivo que nao e PDF
    Quando o Coordenador envia arquivo que nao e PDF
    Entao o sistema rejeita o upload
    E exibe mensagem informando que apenas arquivos PDF sao aceitos

  Cenario: Substituicao de PDF existente
    Dado que o OrcamentoFornecedor ja possui arquivo PDF no MinIO
    Quando o Coordenador faz upload de novo PDF
    Entao o sistema substitui o arquivo antigo no MinIO
    E atualiza a URL pre-assinada no OrcamentoFornecedor
```

### US-M014-024: Selecionar Orcamento Vencedor

Como Coordenador do Projeto,
quero selecionar o orcamento vencedor entre os cadastrados,
para indicar qual fornecedor foi escolhido para a contratacao.

```gherkin
Funcionalidade: Selecionar Orcamento Vencedor

  Cenario: Selecionar orcamento
    Dado que a JustificativaDespesa possui OrcamentoFornecedor sem nenhum marcado como escolhido
    Quando o Coordenador chama MarcarComoEscolhido() em um OrcamentoFornecedor
    Entao o sistema marca Escolhido = true no orcamento selecionado

  Cenario: Trocar orcamento selecionado
    Dado que um OrcamentoFornecedor ja esta marcado como Escolhido = true
    Quando o Coordenador chama MarcarComoEscolhido() em outro orcamento da mesma justificativa
    Entao o sistema chama DesmarcarComoEscolhido() no orcamento anterior
    E marca Escolhido = true no novo orcamento selecionado

  Cenario: Deselecionar orcamento sem substituto
    Dado que apenas um OrcamentoFornecedor esta marcado como Escolhido
    Quando o Coordenador chama DesmarcarComoEscolhido() nele
    Entao o sistema desmarca Escolhido = false
    E a justificativa fica sem orcamento vencedor definido
```

**Definition of Done**

- [x] Testes unitarios cobrindo MarcarComoEscolhido(), DesmarcarComoEscolhido() e exclusividade de escolha
- [x] Testes de integracao: endpoint → persistencia → resposta
- [x] CI verde antes do merge

### US-M014-025: Listar e Editar Orcamentos

Como Coordenador do Projeto,
quero consultar e editar os orcamentos cadastrados para uma justificativa,
para corrigir dados antes da submissao da prestacao de contas.

```gherkin
Funcionalidade: Listar e Editar Orcamentos

  Cenario: Listar orcamentos de uma justificativa
    Dado que existem OrcamentoFornecedor vinculados a uma JustificativaDespesa
    Quando o Coordenador consulta os orcamentos
    Entao o sistema retorna a lista com fornecedor, valor, URL do PDF e indicacao do escolhido

  Cenario: Editar dados de um orcamento
    Dado que a Prestacao esta com status "RASCUNHO"
    Quando o Coordenador atualiza fornecedor ou valor de um OrcamentoFornecedor
    E confirma a edicao
    Entao o sistema persiste as alteracoes

  Cenario: Tentativa de editar orcamento com prestacao em analise
    Dado que a Prestacao esta com status "EM_ANALISE"
    Quando o Coordenador tenta editar um OrcamentoFornecedor
    Entao o sistema impede a edicao
    E exibe mensagem informando que a prestacao ja esta em analise
```

**Definition of Done**

- [x] Testes unitarios cobrindo listagem e bloqueio de edicao fora de RASCUNHO
- [x] Testes de integracao: endpoint → resposta
