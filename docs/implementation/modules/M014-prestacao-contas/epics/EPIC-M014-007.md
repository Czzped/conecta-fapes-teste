# EPIC-M014-007 — Orcamentos de Fornecedor

| Atributo | Valor |
|----------|-------|
| **Status** | Done |
| **Prioridade** | Must |

| **Correspondencia legada** | EP-11 (`deprecated/prestacao-de-contas/feature/ep-11-orcamentos-fornecedor.md`) |

## Contexto

Cada justificativa de despesa pode ter ate tres orcamentos de fornecedor, dos quais um deve ser selecionado como vencedor. Os PDFs dos orcamentos sao armazenados no MinIO.

## User Stories

### US-M014-022 — Criar Orcamentos em Lote

Cadastro de ate tres orcamentos de fornecedor vinculados a uma justificativa, com criacao em lote.

### US-M014-023 — Upload de PDF do Orcamento

Upload de arquivo PDF do orcamento para MinIO com URL pre-assinada.

### US-M014-024 — Selecionar Orcamento Vencedor

Marcacao de um orcamento como escolhido (vencedor), desmarcando os demais.

### US-M014-025 — Listar e Editar Orcamentos

Consulta e edicao de orcamentos existentes por justificativa.
