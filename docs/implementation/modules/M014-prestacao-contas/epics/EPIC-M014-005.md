## Contexto

Documentos fiscais (NF-e e NFS-e) precisam ser validados para garantir autenticidade. Para NF-e, o sistema integra com a API do SERPRO via OAuth2, consultando por chave de acesso de 44 digitos. Para NFS-e, o coordenador faz upload de XML ou PDF. O sistema detecta automaticamente o tipo de arquivo e extrai a chave de acesso quando aplicavel.

## Objetivo

Processar e validar documentos fiscais de forma automatizada, integrando com SERPRO para NF-e e suportando upload direto para NFS-e, com deteccao automatica de formato e extracao de dados fiscais.

### US-M014-015: Processar NF-e via SERPRO

Como Coordenador do Projeto,
quero processar uma Nota Fiscal Eletronica informando a chave de acesso,
para que o sistema valide automaticamente o documento junto ao SERPRO.

```gherkin
Funcionalidade: Processar NF-e via SERPRO

  Cenario: Consulta com ChaveAcesso valida
    Dado que o Coordenador informa ChaveAcesso de exatamente 44 digitos
    Quando confirma o processamento
    Entao o sistema autentica na API SERPRO via OAuth2 (com cache de token)
    E consulta a NF-e pela ChaveAcesso
    E persiste DocumentoFiscal com TipoNota = NF_e e dados retornados (emitente, valor, impostos)
    E registra a ChaveAcesso no DocumentoFiscal (RN01)

  Cenario: ChaveAcesso com formato invalido
    Quando o Coordenador informa ChaveAcesso com numero de digitos diferente de 44
    Entao o sistema impede o processamento antes de chamar o SERPRO
    E exibe mensagem informando que a ChaveAcesso deve conter exatamente 44 digitos

  Cenario: NF-e nao encontrada no SERPRO
    Dado que o Coordenador informa ChaveAcesso valida (44 digitos)
    Quando a API SERPRO retorna erro de documento nao encontrado
    Entao o sistema exibe mensagem informando que a NF-e nao foi localizada
    E nao persiste DocumentoFiscal
```

### US-M014-016: Processar NFS-e por Upload

Como Coordenador do Projeto,
quero fazer upload de um arquivo XML ou PDF de NFS-e,
para registrar servicos prestados por fornecedores que emitem nota de servico.

```gherkin
Funcionalidade: Processar NFS-e por Upload

  Cenario: Upload de XML de NFS-e
    Dado que o Coordenador faz upload de arquivo XML de NFS-e
    Quando confirma o processamento
    Entao o sistema extrai dados do XML (emitente, tomador, valor, impostos)
    E persiste DocumentoFiscal com TipoNota = NFS_e e TipoArquivoNfe = XML
    E armazena o arquivo no MinIO

  Cenario: Upload de PDF de NFS-e
    Dado que o Coordenador faz upload de arquivo PDF de NFS-e
    Quando confirma o processamento
    Entao o sistema persiste DocumentoFiscal com TipoNota = NFS_e e TipoArquivoNfe = PDF
    E armazena o PDF no MinIO com URL pre-assinada

  Cenario: Arquivo com formato invalido
    Quando o Coordenador envia arquivo que nao e XML nem PDF
    Entao o sistema rejeita o upload
    E exibe mensagem informando os formatos aceitos (XML, PDF)
```

### US-M014-017: Detectar Tipo de Arquivo

Como sistema,
quero detectar automaticamente o tipo de arquivo enviado pelo coordenador,
para rotear o processamento adequado (SERPRO ou upload direto).

```gherkin
Funcionalidade: Detectar Tipo de Arquivo

  Cenario: Arquivo XML detectado
    Dado que o Coordenador envia um arquivo
    Quando o conteudo do arquivo e XML valido
    Entao o sistema identifica TipoArquivoNfe = XML
    E roteia para extracao de dados fiscais e tentativa de consulta no SERPRO

  Cenario: Arquivo PDF detectado
    Dado que o Coordenador envia um arquivo
    Quando o conteudo do arquivo e PDF
    Entao o sistema identifica TipoArquivoNfe = PDF
    E roteia para upload direto no MinIO

  Cenario: Arquivo com extensao incompativel com conteudo
    Dado que o Coordenador envia arquivo com extensao .xml
    Quando o conteudo nao corresponde a XML valido
    Entao o sistema rejeita o arquivo
    E exibe mensagem informando que o arquivo esta corrompido ou com formato invalido
```

### US-M014-018: Extrair Chave de Acesso

Como sistema,
quero extrair a chave de acesso de 44 digitos de um arquivo XML de NF-e,
para usar na consulta automatica ao SERPRO sem entrada manual do coordenador.

```gherkin
Funcionalidade: Extrair Chave de Acesso

  Cenario: Extracao de ChaveAcesso a partir de XML NF-e
    Dado que o Coordenador envia arquivo XML de NF-e
    Quando o sistema processa o XML
    Entao extrai a ChaveAcesso de 44 digitos do campo correspondente
    E usa a ChaveAcesso extraida para consulta automatica no SERPRO (US-M014-015)

  Cenario: XML sem ChaveAcesso
    Dado que o Coordenador envia XML que nao contem campo de ChaveAcesso
    Quando o sistema tenta extrair a chave
    Entao retorna erro informando que o XML nao contem chave de acesso valida
    E solicita ao Coordenador que informe a ChaveAcesso manualmente
```
