## Contexto

Documentos fiscais (NF-e e NFS-e) precisam ser validados automaticamente. O sistema integra com a API do SERPRO para consulta de NF-e por chave de acesso (44 digitos). Suporta upload de XML, PDF e imagem, com deteccao automatica do tipo de arquivo e extracao de chave de acesso.

## User Stories

### US-M014-015 — Processar NF-e via SERPRO

Consulta da NF-e na API SERPRO por chave de acesso com autenticacao OAuth2 e cache de token.

### US-M014-016 — Processar NFS-e por Upload

Upload de XML/PDF de NFS-e com extracao de dados (emitente, valor, impostos).

### US-M014-017 — Detectar Tipo de Arquivo (XML/PDF)

Identificacao automatica do tipo de arquivo enviado para processamento adequado.

### US-M014-018 — Extrair Chave de Acesso

Extracao da chave de acesso de 44 digitos a partir do conteudo do documento fiscal.
