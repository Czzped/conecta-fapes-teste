# EPIC-M003-001 — Registrar Edital Operacional

| Atributo | Valor |
|----------|-------|
| **Status** | Done |
| **Prioridade** | Must |
| **Dependencias** | Nenhuma |
| **Operacao do contrato** | RegistrarEditalOperacional |

## Contexto

O edital e a unidade operacional publicada pela agencia de fomento. Deve estar vinculado a uma AreaTecnica (M008) e opcionalmente a um Programa ou Parceria (M010). O M002 pode importar editais do SIGFAPES, mas o ownership permanece no M003.

## User Stories

### US-M003-001 — Criar Edital com Area Tecnica
Cadastro de edital operacional com vinculo obrigatorio a AreaTecnica.

### US-M003-002 — Atualizar Edital Operacional
Atualizacao de dados do edital existente.

### US-M003-003 — Vincular Edital a Programa/Parceria
Associacao opcional do edital a Programa ou Parceria do M010.
