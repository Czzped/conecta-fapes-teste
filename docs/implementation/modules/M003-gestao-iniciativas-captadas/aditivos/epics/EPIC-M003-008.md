## Contexto

A tela **Meu Projeto** deve apresentar ao usuario uma visao clara da vigencia da iniciativa, incluindo data inicial, data final vigente e indicacao se a iniciativa recebeu aditivo de tempo ou aditivo financeiro.

Essas informacoes sao relevantes para coordenadores e bolsistas acompanharem o periodo de execucao, entenderem se houve prorrogacao formal e identificarem se o projeto recebeu acrescimo financeiro. A visao deve preservar historico: a data final vigente pode ser diferente da data final original quando houver aditivo de tempo.

## Objetivo

Permitir consultar e exibir, na tela **Meu Projeto**, os dados de vigencia e aditivos da iniciativa: data inicial, data final original, data final vigente, existencia de aditivo de tempo, existencia de aditivo financeiro e valores/observacoes resumidas quando aplicavel. Em **Projetos**, a visualizacao deve possuir uma aba especifica de aditivos para listar os dados dos aditivos quando existirem.

## Escopo

Inclui:

- Exibir data inicial da iniciativa.
- Exibir data final original da iniciativa.
- Exibir data final vigente da iniciativa.
- Indicar se houve aditivo de tempo.
- Indicar se houve aditivo financeiro.
- Exibir resumo do impacto do aditivo de tempo, quando houver.
- Exibir resumo do impacto do aditivo financeiro, quando houver.
- Disponibilizar os dados na tela **Meu Projeto** para bolsista e coordenador.
- Disponibilizar, no bloco **Vigencia e aditivos** da tela **Meu Projeto**, abas internas para alternar entre **Resumo** e **Dados dos aditivos**.
- Exibir, na aba **Dados dos aditivos**, a data de aprovacao original do projeto e o orcamento original aprovado.
- Disponibilizar, na area **Projetos**, uma aba **Aditivos** com a lista dos aditivos vinculados ao projeto quando houver registros.
- Exibir estado vazio na aba **Aditivos** quando o projeto nao possuir aditivos cadastrados/aprovados.

Nao inclui:

- Fluxo de solicitacao, analise ou aprovacao de aditivo.
- Upload de termo aditivo.
- Recalculo contabil detalhado de aporte financeiro.
- Prestacao de contas do valor aditivado.

## User Stories

### US-M003-038 - Consultar vigencia da iniciativa

Como usuario vinculado a uma iniciativa,
quero visualizar a data inicial e a data final vigente do projeto,
para entender o periodo formal de execucao.

### US-M003-039 - Identificar aditivo de tempo

Como coordenador ou bolsista,
quero saber se o projeto foi aditivado em tempo,
para entender se a data final vigente decorre de prorrogacao.

### US-M003-040 - Identificar aditivo financeiro

Como coordenador ou bolsista,
quero saber se o projeto foi aditivado em dinheiro,
para entender se houve acrescimo de recursos ao projeto.

### US-M003-041 - Listar dados dos aditivos no bloco Vigencia e aditivos

Como usuario com acesso ao projeto,
quero acessar a aba **Dados dos aditivos** no bloco **Vigencia e aditivos**,
para consultar os dados dos aditivos existentes, seus tipos, datas, valores, impactos de prazo e documentos de referencia.

## Regras de Dominio

| ID | Regra |
|----|-------|
| RD01 | Toda iniciativa deve possuir data inicial e data final original. |
| RD02 | A data final vigente deve ser igual a data final original quando nao houver aditivo de tempo. |
| RD03 | Quando houver aditivo de tempo aprovado, a data final vigente deve refletir a ultima data final aprovada. |
| RD04 | A interface deve indicar explicitamente se houve aditivo de tempo. |
| RD05 | A interface deve indicar explicitamente se houve aditivo financeiro. |
| RD06 | A existencia de aditivo financeiro nao altera por si so a data final vigente. |
| RD07 | A existencia de aditivo de tempo nao altera por si so o valor financeiro do projeto. |
| RD08 | A consulta deve estar disponivel para usuarios vinculados a iniciativa, respeitando as permissoes do perfil. |
| RD09 | O bloco **Vigencia e aditivos** em **Meu Projeto** deve possuir abas internas **Resumo** e **Dados dos aditivos**. |
| RD10 | A aba **Resumo** deve exibir as datas e indicadores consolidados de vigencia, aditivo de tempo e aditivo financeiro. |
| RD11 | A aba **Dados dos aditivos** deve exibir a data de aprovacao original do projeto, o orcamento original aprovado e a lista de aditivos vinculados ao projeto selecionado e visiveis conforme o perfil do usuario. |
| RD12 | Quando nao houver aditivos, a aba **Dados dos aditivos** deve exibir estado vazio informando que o projeto nao possui aditivos registrados. |
| RD13 | A area **Projetos** pode expor tambem uma aba **Aditivos** para consulta dos mesmos dados dos aditivos vinculados ao projeto. |
| RD14 | Cada item da lista de aditivos deve indicar, no minimo, tipo do aditivo, situacao, data de aprovacao ou publicacao, impacto de prazo ou valor e documento de referencia quando disponivel. |

## Dados Esperados

| Campo | Descricao |
|-------|-----------|
| `dataInicio` | Data inicial formal da iniciativa. |
| `dataAprovacaoOriginal` | Data de aprovacao original do projeto antes de qualquer aditivo. |
| `dataFimOriginal` | Data final originalmente contratada. |
| `dataFimVigente` | Data final atual, considerando aditivos de tempo aprovados. |
| `orcamentoOriginal` | Orcamento originalmente aprovado para a iniciativa. |
| `possuiAditivoTempo` | Indica se houve prorrogacao de prazo. |
| `diasAditados` | Quantidade de dias adicionados ao prazo, quando aplicavel. |
| `possuiAditivoFinanceiro` | Indica se houve acrescimo financeiro. |
| `valorAditivado` | Valor total aditivado em dinheiro, quando aplicavel. |
| `documentoReferencia` | Referencia do termo/documento do aditivo, quando disponivel. |
| `aditivos[]` | Lista de aditivos vinculados ao projeto. |
| `aditivos[].id` | Identificador do aditivo. |
| `aditivos[].tipo` | Tipo do aditivo: tempo, financeiro ou tempo e financeiro. |
| `aditivos[].situacao` | Situacao atual do aditivo. |
| `aditivos[].dataAprovacao` | Data de aprovacao, publicacao ou formalizacao do aditivo, quando disponivel. |
| `aditivos[].dataFimAnterior` | Data final vigente antes do aditivo de tempo, quando aplicavel. |
| `aditivos[].dataFimAditada` | Nova data final aprovada pelo aditivo de tempo, quando aplicavel. |
| `aditivos[].valorAditivado` | Valor financeiro acrescido pelo aditivo, quando aplicavel. |
| `aditivos[].documentoReferencia` | Numero, link ou identificacao do termo/documento do aditivo, quando disponivel. |
| `aditivos[].observacao` | Observacao resumida do aditivo, quando disponivel. |

## Protótipo

- Front-Office: tela **Meu Projeto** exibe bloco "Vigencia e aditivos" com abas internas **Resumo** e **Dados dos aditivos**.
- Aba **Resumo**: exibe data inicial, data final vigente e indicadores de aditivo de tempo e dinheiro.
- Aba **Dados dos aditivos**: exibe data de aprovacao original, orcamento original e os aditivos vinculados ao projeto, com tipo, situacao, data de formalizacao, impacto de prazo/valor e documento de referencia.
- Projetos: tela de detalhe do projeto possui a aba **Aditivos** ao lado das demais abas de consulta do projeto.
- Aba **Aditivos**: quando houver registros, exibe lista tabular ou cards compactos com tipo, situacao, data de formalizacao, impacto de prazo/valor e documento de referencia.
- Aba **Aditivos**: quando nao houver registros, exibe estado vazio com mensagem objetiva informando ausencia de aditivos.
