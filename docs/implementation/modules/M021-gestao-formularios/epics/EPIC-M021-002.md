# EPIC-M021-002 - Versionamento e Publicacao de Formularios

| Atributo | Valor |
|----------|-------|
| **Status** | To Do |
| **Prioridade** | Must |
| **Operacao do contrato** | CriarVersaoFormulario, PublicarVersaoFormulario |

## Contexto

Formularios usados em captacoes e outros fluxos precisam ser versionados para preservar rastreabilidade. Uma versao publicada nao pode ser editada diretamente.

## User Stories

### US-M021-004 - Criar versao de formulario
Como Gestor da FAPES, quero criar uma nova versao em rascunho.

### US-M021-005 - Publicar versao de formulario
Como Gestor da FAPES, quero publicar uma versao valida para que outros modulos possam seleciona-la.

### US-M021-006 - Criar nova versao a partir de versao publicada
Como Gestor da FAPES, quero derivar uma nova versao a partir de uma versao ja publicada.
