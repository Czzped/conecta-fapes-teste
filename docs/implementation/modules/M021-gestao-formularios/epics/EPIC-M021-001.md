# EPIC-M021-001 - Cadastrar Categoria de Formulario

| Atributo | Valor |
|----------|-------|
| **Release** | 1 |
| **Status** | To Do |
| **Prioridade** | Should |
| **Regras de negocio** | RN14, RN15, RN27, RN31 |
| **Operacoes do contrato** | CriarCategoriaFormulario, ConsultarCategoriaFormulario, AtualizarCategoriaFormulario, ExcluirCategoriaFormulario, ListarCategoriasFormulario |

## Contexto

O M021 pode classificar formularios em categorias para facilitar organizacao, busca e reutilizacao. Este EPIC nao e fundamental para a Release 1: se reduzir o tempo de entrega, as categorias podem ser pre-cadastradas diretamente no banco de dados.

## Escopo

- Criar categoria de formulario.
- Consultar categoria de formulario.
- Atualizar categoria de formulario.
- Excluir categoria de formulario, quando nao houver impedimento de uso.
- Listar categorias disponiveis para classificacao de formularios.

## User Stories

### US-M021-001 - Criar categoria

Como funcionario da FAPES, quero cadastrar categorias de formulario para organizar os formularios disponiveis no modulo.

```gherkin
Funcionalidade: Criar categoria de formulario

  Cenario: Criacao de categoria com dados validos
    Dado que o funcionario da FAPES esta autenticado
    Quando informa nome e descricao da categoria
    E confirma o cadastro
    Entao o sistema registra a categoria
    E a categoria fica disponivel para classificacao de formularios

  Cenario: Tentativa de criar categoria sem nome
    Dado que o funcionario da FAPES esta cadastrando uma categoria
    Quando tenta salvar sem informar o nome
    Entao o sistema rejeita o cadastro
    E informa que o nome da categoria e obrigatorio
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `POST /categorias` | CriarCategoriaFormulario | Endpoint principal para registrar a nova categoria informada pelo funcionario da FAPES. |
| `GET /categorias` | ListarCategoriasFormulario | Endpoint de apoio para atualizar a listagem apos a criacao e permitir verificar que a categoria ficou disponivel. |

### US-M021-002 - Consultar categoria

Como funcionario da FAPES, quero consultar os dados de uma categoria para verificar sua descricao e uso.

```gherkin
Funcionalidade: Consultar categoria de formulario

  Cenario: Consulta de categoria existente
    Dado que existe uma categoria cadastrada
    Quando o funcionario da FAPES consulta a categoria
    Entao o sistema apresenta nome e descricao da categoria
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `GET /categorias` | ListarCategoriasFormulario | Endpoint de apoio para localizar a categoria que sera consultada. |
| `GET /categorias/{categoriaId}` | ConsultarCategoriaFormulario | Endpoint principal para carregar nome e descricao da categoria selecionada. |

### US-M021-003 - Atualizar categoria

Como funcionario da FAPES, quero atualizar categorias para manter sua nomenclatura adequada ao uso do modulo.

```gherkin
Funcionalidade: Atualizar categoria de formulario

  Cenario: Atualizacao de categoria existente
    Dado que existe uma categoria cadastrada
    Quando o funcionario da FAPES altera nome ou descricao da categoria
    E confirma a alteracao
    Entao o sistema atualiza a categoria
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `GET /categorias` | ListarCategoriasFormulario | Endpoint de apoio para localizar a categoria que sera alterada. |
| `GET /categorias/{categoriaId}` | ConsultarCategoriaFormulario | Endpoint de apoio para carregar os dados atuais antes da edicao. |
| `PUT /categorias/{categoriaId}` | AtualizarCategoriaFormulario | Endpoint principal para persistir as alteracoes de nome ou descricao. |

### US-M021-004 - Excluir categoria

Como funcionario da FAPES, quero excluir categorias que nao devem mais ser usadas.

```gherkin
Funcionalidade: Excluir categoria de formulario

  Cenario: Exclusao de categoria sem formulario associado
    Dado que existe uma categoria sem formularios associados
    Quando o funcionario da FAPES solicita a exclusao
    Entao o sistema remove a categoria

  Cenario: Tentativa de excluir categoria em uso
    Dado que existe uma categoria associada a pelo menos um formulario
    Quando o funcionario da FAPES solicita a exclusao
    Entao o sistema rejeita a exclusao
    E preserva a categoria
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `GET /categorias` | ListarCategoriasFormulario | Endpoint de apoio para localizar a categoria que sera excluida. |
| `GET /categorias/{categoriaId}` | ConsultarCategoriaFormulario | Endpoint de apoio para apresentar os dados da categoria antes da confirmacao de exclusao. |
| `DELETE /categorias/{categoriaId}` | ExcluirCategoriaFormulario | Endpoint principal para excluir a categoria, respeitando a regra de que ela nao esteja associada a nenhum formulario. |

### US-M021-005 - Listar categorias

Como funcionario da FAPES, quero listar categorias para selecionar classificacoes ao cadastrar ou consultar formularios.

```gherkin
Funcionalidade: Listar categorias de formulario

  Cenario: Listagem de categorias cadastradas
    Dado que existem categorias cadastradas
    Quando o funcionario da FAPES acessa a listagem de categorias
    Entao o sistema apresenta as categorias disponiveis
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `GET /categorias` | ListarCategoriasFormulario | Endpoint principal para apresentar as categorias disponiveis para selecao, consulta ou manutencao. |

## Criterios de Aceite

- A categoria deve possuir nome e descricao.
- Um formulario pode ser classificado em zero ou mais categorias.
- Todas as funcionalidades de categorias devem ser acessiveis por funcionario da FAPES autenticado.
- A Release 1 pode ser entregue com categorias pre-cadastradas se o CRUD de categorias for postergado.
