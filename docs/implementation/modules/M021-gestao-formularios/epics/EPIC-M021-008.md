## Contexto

Esta release adequa o gerenciamento de respostas para formularios de habilitacao. A prioridade nao e Must porque respostas de habilitacao nao devem ser tratadas no primeiro momento da Release 1.

## Escopo

- Iniciar resposta de formulario de habilitacao.
- Editar resposta de habilitacao em rascunho.
- Enviar resposta de habilitacao.
- Calcular resultado de habilitacao conforme respostas "Rever", "Nao" e demais valores permitidos.
- Consultar e listar respostas de habilitacao.

## User Stories

### US-M021-023 - Gerenciar respostas de formulario de habilitacao

Como modulo interno, quero registrar respostas de habilitacao para obter o resultado consolidado da verificacao.

```gherkin
Funcionalidade: Gerenciar respostas de formulario de habilitacao

  Cenario: Envio de resposta com ao menos uma questao marcada como Rever
    Dado que existe uma resposta de habilitacao em estado "RASCUNHO"
    E ao menos uma questao foi respondida como "Rever"
    Quando o usuario respondedor envia a resposta
    Entao o sistema altera a resposta para "ENVIADA"
    E registra a data de envio
    E define o resultado como "Rever"

  Cenario: Envio de resposta com ao menos uma questao marcada como Nao
    Dado que existe uma resposta de habilitacao em estado "RASCUNHO"
    E nenhuma questao foi respondida como "Rever"
    E ao menos uma questao foi respondida como "Nao"
    Quando o usuario respondedor envia a resposta
    Entao o sistema define o resultado como "Inabilitado"

  Cenario: Envio de resposta sem Rever nem Nao
    Dado que existe uma resposta de habilitacao em estado "RASCUNHO"
    E nenhuma questao foi respondida como "Rever" ou "Nao"
    Quando o usuario respondedor envia a resposta
    Entao o sistema define o resultado como "Habilitado"

  Cenario: Tentativa de editar resposta de habilitacao enviada
    Dado que existe uma resposta de habilitacao em estado "ENVIADA"
    Quando o usuario respondedor tenta altera-la
    Entao o sistema rejeita a alteracao
```

## Criterios de Aceite

- Respostas seguem o ciclo "RASCUNHO" para "ENVIADA".
- Apenas respostas em rascunho podem ser editadas.
- O resultado deve ser "Rever" quando ao menos uma questao tiver resposta "Rever".
- O resultado deve ser "Inabilitado" quando nao houver "Rever" e ao menos uma questao tiver resposta "Nao".
- O resultado deve ser "Habilitado" quando nao houver respostas "Rever" nem "Nao".
