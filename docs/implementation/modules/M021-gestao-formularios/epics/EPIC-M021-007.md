## Contexto

Esta release adequa o cadastro de formularios para formularios de habilitacao. A prioridade nao e Must porque a Release 1 deve focar primeiro nos formularios de caracterizacao.

## Escopo

- Cadastrar formulario do tipo "Habilitacao".
- Configurar questoes no formato padronizado de habilitacao.
- Manter o mesmo ciclo de criacao, edicao, consulta, exclusao e listagem previsto para formularios.

## User Stories

### US-M021-022 - Cadastrar formulario de habilitacao

Como Gestor da FAPES, quero cadastrar formularios de habilitacao para coletar respostas padronizadas de verificacao.

```gherkin
Funcionalidade: Cadastrar formulario de habilitacao

  Cenario: Criacao de formulario de habilitacao valido
    Dado que o Gestor da FAPES esta criando um formulario
    Quando informa tipo "Habilitacao"
    E configura questoes com respostas possiveis "Sim", "Nao", "Nao se aplica" ou "Rever"
    E inclui campo textual de justificativa
    Entao o sistema cria o formulario em estado "Em Edicao"

  Cenario: Tentativa de salvar habilitacao com formato de questao invalido
    Dado que o Gestor da FAPES esta criando um formulario de habilitacao
    Quando configura uma questao fora do formato padronizado
    Entao o sistema rejeita a configuracao da questao
```

## Criterios de Aceite

- Formularios de habilitacao devem possuir questoes no formato padronizado definido em RN18.
- O formulario de habilitacao segue as mesmas regras gerais de cadastro, edicao e exclusao de formularios.
