# EPIC-M021-004 - Gerenciar Respostas de Formulario de Caracterizacao

| Atributo | Valor |
|----------|-------|
| **Release** | 1 |
| **Status** | To Do |
| **Prioridade** | Must |
| **Regras de negocio** | RN09, RN12, RN17, RN24-RN26 |
| **Operacoes do contrato** | RegistrarRespostaFormulario, AtualizarRespostaFormulario, EnviarRespostaFormulario, ConsultarRespostaFormulario, ListarRespostasFormulario |

## Contexto

Respostas de formularios de caracterizacao registram os dados preenchidos em usos concretos do formulario, como a submissao de um projeto. O respondedor pode iniciar uma resposta, salva-la como rascunho, editar o rascunho e envia-la quando o preenchimento estiver concluido.

## Escopo

- Iniciar resposta de formulario de caracterizacao.
- Editar resposta enquanto estiver em rascunho.
- Enviar resposta em rascunho.
- Consultar resposta.
- Listar respostas de um formulario.

## User Stories

### US-M021-015 - Iniciar resposta de formulario de caracterizacao

Como usuario respondedor, quero iniciar uma resposta de formulario de caracterizacao para preencher dados de submissao ao longo do tempo.

```gherkin
Funcionalidade: Iniciar resposta de formulario de caracterizacao

  Cenario: Inicio de resposta para formulario utilizado
    Dado que existe um formulario de caracterizacao em estado "Utilizado"
    Quando o modulo interno solicita o registro de uma resposta
    Entao o sistema cria a resposta em estado "RASCUNHO"
    E registra data de criacao, usuario de criacao, data da ultima alteracao e usuario da ultima alteracao
```

### US-M021-016 - Editar resposta em rascunho

Como usuario respondedor, quero editar uma resposta em rascunho para completar ou corrigir o preenchimento antes do envio.

```gherkin
Funcionalidade: Editar resposta em rascunho

  Cenario: Edicao de resposta em rascunho
    Dado que existe uma resposta em estado "RASCUNHO"
    Quando o usuario respondedor altera os valores preenchidos
    Entao o sistema atualiza a resposta
    E registra data e usuario da ultima alteracao

  Cenario: Tentativa de editar resposta enviada
    Dado que existe uma resposta em estado "ENVIADA"
    Quando o usuario respondedor tenta altera-la
    Entao o sistema rejeita a alteracao
```

### US-M021-017 - Enviar resposta

Como usuario respondedor, quero enviar uma resposta em rascunho para concluir o preenchimento.

```gherkin
Funcionalidade: Enviar resposta de formulario de caracterizacao

  Cenario: Envio de resposta em rascunho
    Dado que existe uma resposta de formulario de caracterizacao em estado "RASCUNHO"
    Quando o usuario respondedor envia a resposta
    Entao o sistema altera o estado da resposta para "ENVIADA"
    E registra a data de envio

  Cenario: Tentativa de enviar resposta ja enviada
    Dado que existe uma resposta em estado "ENVIADA"
    Quando o usuario respondedor solicita novo envio
    Entao o sistema rejeita a operacao
```

### US-M021-018 - Consultar resposta

Como usuario autorizado, quero consultar uma resposta para visualizar os dados preenchidos e seu estado.

```gherkin
Funcionalidade: Consultar resposta de formulario

  Cenario: Consulta de resposta existente
    Dado que existe uma resposta registrada
    Quando um usuario autorizado consulta a resposta
    Entao o sistema apresenta os dados preenchidos, estado, datas e usuarios de rastreabilidade
```

### US-M021-019 - Listar respostas

Como usuario autorizado, quero listar respostas de um formulario para acompanhar preenchimentos associados a seus usos.

```gherkin
Funcionalidade: Listar respostas de formulario

  Cenario: Listagem de respostas por formulario
    Dado que existem respostas registradas para um formulario
    Quando um usuario autorizado solicita a listagem
    Entao o sistema retorna as respostas associadas ao formulario
    E permite diferenciar respostas em rascunho e enviadas
```

## Criterios de Aceite

- Respostas devem iniciar em estado "RASCUNHO".
- Respostas em rascunho podem ser editadas pelo usuario responsavel pelo preenchimento.
- Respostas enviadas nao podem mais ser alteradas pelo respondedor.
- Respostas de caracterizacao nao computam resultado.
