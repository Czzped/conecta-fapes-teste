# EPIC-M021-004 - Consulta e Selecao de Formularios por Modulos

| Atributo | Valor |
|----------|-------|
| **Status** | To Do |
| **Prioridade** | Must |
| **Operacao do contrato** | ListarFormulariosPublicados, ConsultarVersaoFormulario |

## Contexto

Modulos como M011 precisam selecionar formularios publicados e consultar sua estrutura versionada para configurar e executar processos.

## User Stories

### US-M021-010 - Listar formularios ativos por classificacao
Como modulo consumidor, quero listar formularios publicados por tipo e finalidade.

```gherkin
Funcionalidade: Listar Formularios Publicados por Classificacao

  Cenario: Listagem de formularios publicados por tipo
    Dado que existem formularios com status "Publicado" dos tipos "Inscricao", "Avaliacao Ad Hoc" e "Revisao de Resultado"
    Quando o modulo consumidor solicita a listagem de formularios pelo tipo "Inscricao"
    Entao o sistema retorna apenas os formularios publicados classificados como tipo "Inscricao"
    E formularios com status "Rascunho" ou "Inativo" nao aparecem no resultado

  Cenario: Listagem de formularios publicados por finalidade
    Dado que existem formularios publicados com finalidades distintas
    Quando o modulo consumidor solicita a listagem de formularios pela finalidade "Avaliacao"
    Entao o sistema retorna apenas os formularios publicados com finalidade "Avaliacao"

  Cenario: Listagem retorna vazia quando nenhum formulario publicado corresponde ao filtro
    Dado que nao existem formularios publicados do tipo "Revisao de Resultado"
    Quando o modulo consumidor solicita a listagem pelo tipo "Revisao de Resultado"
    Entao o sistema retorna uma lista vazia
    E nao retorna formularios de outros tipos ou com outros status

  Cenario: Formulario inativado nao aparece na listagem para novas selecoes
    Dado que o formulario "Formulario de Inscricao PIBIC 2023" foi inativado
    Quando o modulo M011 solicita a listagem de formularios publicados do tipo "Inscricao"
    Entao o formulario "Formulario de Inscricao PIBIC 2023" nao aparece no resultado

  Cenario: Cada formulario na listagem exibe nome, tipo, finalidade e versao mais recente publicada
    Dado que existem formularios publicados
    Quando o modulo consumidor solicita a listagem
    Entao cada item do resultado contem o nome, o tipo, a finalidade e o numero da versao mais recente publicada
```

### US-M021-011 - Consultar versao publicada do formulario
Como modulo consumidor, quero consultar a estrutura completa de uma versao publicada.

```gherkin
Funcionalidade: Consultar Versao Publicada do Formulario

  Cenario: Consulta de versao publicada com estrutura completa
    Dado que o formulario "Formulario de Avaliacao Ad Hoc" possui a versao "2" com status "Publicada"
    Quando o modulo consumidor consulta a versao "2" desse formulario
    Entao o sistema retorna a estrutura completa contendo secoes, campos, tipos, rotulos, obrigatoriedades e regras condicionais dessa versao

  Cenario: Tentativa de consultar versao em rascunho por modulo consumidor
    Dado que o formulario "Formulario de Revisao" possui uma versao com status "Rascunho"
    Quando o modulo consumidor tenta consultar essa versao
    Entao o sistema exibe a mensagem "Esta versao nao esta publicada e nao esta disponivel para consulta"
    E nao retorna a estrutura da versao

  Cenario: Consulta de versao inexistente
    Dado que o formulario "Formulario de Inscricao PIBIC" nao possui a versao "99"
    Quando o modulo consumidor tenta consultar a versao "99" desse formulario
    Entao o sistema exibe a mensagem "A versao solicitada nao foi encontrada para este formulario"

  Cenario: Estrutura da versao publicada reflete exatamente o estado no momento da publicacao
    Dado que a versao "1" do formulario foi publicada com os campos "Titulo" e "Resumo"
    E posteriormente o Gestor criou e publicou a versao "2" adicionando o campo "Palavras-chave"
    Quando o modulo consumidor consulta a versao "1"
    Entao o sistema retorna apenas os campos "Titulo" e "Resumo" sem incluir "Palavras-chave"
```
