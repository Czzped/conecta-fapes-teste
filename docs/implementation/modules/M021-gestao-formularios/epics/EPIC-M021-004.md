# EPIC-M021-004 - Consulta e Selecao de Formularios por Modulos

| Atributo | Valor |
|----------|-------|
| **Status** | To Do |
| **Prioridade** | Must |
| **Operacao do contrato** | ListarFormulariosPublicados, ConsultarVersaoFormulario |

## Contexto

Modulos como M011 precisam selecionar formularios publicados e consultar sua estrutura versionada para configurar e executar processos.

## User Stories

### US-M021-010 - Listar formularios ativos por classificacao
Como modulo consumidor, quero listar formularios publicados por tipo e finalidade.

### US-M021-011 - Consultar versao publicada do formulario
Como modulo consumidor, quero consultar a estrutura completa de uma versao publicada.
