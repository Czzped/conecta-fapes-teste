# EPIC-M021-003 - Gerenciar Ciclo de Vida de Formulario

| Atributo | Valor |
|----------|-------|
| **Release** | 1 |
| **Status** | To Do |
| **Prioridade** | Must |
| **Regras de negocio** | RN07-RN12 |
| **Operacoes do contrato** | PublicarFormulario, ReverterPublicacaoFormulario, NotificarUsoFormulario, InativarFormulario |

## Contexto

O formulario possui ciclo de vida proprio para controlar quando pode ser editado, publicado, utilizado por outros modulos, revertido ou inativado. Esse ciclo garante que formularios ja utilizados mantenham estabilidade para respostas e rastreabilidade.

## Escopo

- Publicar formulario em edicao.
- Reverter publicacao de formulario ainda nao utilizado.
- Notificar o primeiro uso de formulario publicado por outro modulo.
- Inativar formulario publicado ou utilizado.

## User Stories

### US-M021-011 - Publicar formulario

Como Gestor da FAPES, quero publicar um formulario valido para que outros modulos possam utiliza-lo.

```gherkin
Funcionalidade: Publicar formulario

  Cenario: Publicacao de formulario em edicao
    Dado que existe um formulario em estado "Em Edicao"
    Quando o Gestor da FAPES solicita a publicacao
    Entao o sistema altera o estado do formulario para "Publicado"
    E registra data de publicacao, data da ultima alteracao e usuario da ultima alteracao

  Cenario: Tentativa de publicar formulario fora de edicao
    Dado que existe um formulario em estado diferente de "Em Edicao"
    Quando o Gestor da FAPES solicita a publicacao
    Entao o sistema rejeita a transicao
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `GET /formularios` | ListarFormularios | Endpoint de apoio para localizar formularios em estado "Em Edicao". |
| `GET /formularios/{formularioId}` | ConsultarFormulario | Endpoint de apoio para revisar dados e estrutura antes da publicacao. |
| `POST /formularios/{formularioId}/publicar` | PublicarFormulario | Endpoint principal para publicar o formulario e registrar os dados da transicao. |

### US-M021-012 - Reverter publicacao de formulario

Como Gestor da FAPES, quero reverter a publicacao de um formulario ainda nao utilizado para corrigi-lo.

```gherkin
Funcionalidade: Reverter publicacao de formulario

  Cenario: Reversao de formulario publicado e nao utilizado
    Dado que existe um formulario em estado "Publicado"
    E o formulario ainda nao foi utilizado por outro modulo
    Quando o Gestor da FAPES solicita a reversao da publicacao
    Entao o sistema altera o estado do formulario para "Em Edicao"
    E limpa a data de publicacao
    E registra data e usuario da ultima alteracao

  Cenario: Tentativa de reverter formulario utilizado
    Dado que existe um formulario em estado "Utilizado"
    Quando o Gestor da FAPES solicita a reversao da publicacao
    Entao o sistema rejeita a reversao
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `GET /formularios` | ListarFormularios | Endpoint de apoio para localizar formularios publicados. |
| `GET /formularios/{formularioId}` | ConsultarFormulario | Endpoint de apoio para verificar estado e dados do formulario antes da reversao. |
| `POST /formularios/{formularioId}/reverter-publicacao` | ReverterPublicacaoFormulario | Endpoint principal para voltar o formulario para "Em Edicao" quando ele ainda nao tiver sido utilizado. |

### US-M021-013 - Notificar uso de formulario

Como modulo interno, quero notificar que um formulario publicado foi utilizado para que o M021 preserve seu ciclo de vida.

```gherkin
Funcionalidade: Notificar uso de formulario

  Cenario: Primeiro uso de formulario publicado
    Dado que existe um formulario em estado "Publicado"
    Quando um modulo interno notifica o uso do formulario
    Entao o sistema altera o estado do formulario para "Utilizado"
    E registra a data do primeiro uso

  Cenario: Notificacao de uso quando a data do primeiro uso ja existe
    Dado que existe um formulario com data do primeiro uso preenchida
    Quando um modulo interno notifica o uso do formulario
    Entao o sistema nao altera a data do primeiro uso
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `GET /formularios/publicados` | ListarFormulariosPublicados | Endpoint de apoio para modulos internos localizarem formularios disponiveis para novo uso. |
| `GET /formularios/{formularioId}` | ConsultarFormulario | Endpoint de apoio para consultar o formulario que sera utilizado. |
| `POST /formularios/{formularioId}/usos` | NotificarUsoFormulario | Endpoint principal para notificar o uso, alterar o estado para "Utilizado" e registrar a data do primeiro uso quando aplicavel. |

### US-M021-014 - Inativar formulario

Como Gestor da FAPES, quero inativar formularios publicados ou utilizados para impedir novos usos.

```gherkin
Funcionalidade: Inativar formulario

  Cenario: Inativacao de formulario publicado ou utilizado
    Dado que existe um formulario em estado "Publicado" ou "Utilizado"
    Quando o Gestor da FAPES solicita a inativacao
    Entao o sistema altera o estado do formulario para "Inativo"
    E registra a data de inativacao se o formulario ainda nao estava inativo

  Cenario: Formulario inativo nao fica disponivel para novos usos
    Dado que existe um formulario em estado "Inativo"
    Quando um modulo interno solicita formularios disponiveis para novo uso
    Entao o formulario inativo nao e retornado
```

#### Endpoints relacionados

| Endpoint | Operacao | Relacao com a US |
|----------|----------|------------------|
| `GET /formularios` | ListarFormularios | Endpoint de apoio para localizar formularios publicados ou utilizados que podem ser inativados. |
| `GET /formularios/{formularioId}` | ConsultarFormulario | Endpoint de apoio para apresentar dados e estado antes da confirmacao de inativacao. |
| `POST /formularios/{formularioId}/inativar` | InativarFormulario | Endpoint principal para inativar o formulario e registrar a data de inativacao quando aplicavel. |
| `GET /formularios/publicados` | ListarFormulariosPublicados | Endpoint de apoio para validar que formularios inativos nao aparecem para novos usos. |

## Criterios de Aceite

- Formularios publicados ficam visiveis para uso por outros modulos e deixam de permitir edicao direta.
- Formularios utilizados nao podem ter publicacao revertida.
- A notificacao de uso registra apenas a data do primeiro uso quando ela ainda nao estiver preenchida.
- A inativacao registra apenas a data de inativacao quando o formulario ainda nao estiver inativo.
