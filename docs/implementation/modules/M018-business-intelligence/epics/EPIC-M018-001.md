## Contexto

A Diretoria e a Area Tecnica da agencia de fomento necessitam de paineis analiticos que consolidem informacoes sobre programas de fomento e projetos financiados. Atualmente, a producao de relatorios gerenciais exige compilacao manual de dados de diferentes fontes, o que consome tempo e gera inconsistencias. Sem dashboards estruturados, a tomada de decisao estrategica fica baseada em informacoes fragmentadas e desatualizadas.

Este EPIC e o fundacional do modulo M018: os paineis de programas e projetos fornecem a base sobre a qual os paineis de bolsas e resultados serao construidos.

## Objetivo

Fornecer dashboards interativos para visualizacao consolidada de programas de fomento e projetos por edital, com indicadores de desempenho, filtros por periodo/programa/edital/instituicao e exportacao para PDF e Excel.

### US-M018-001: Dashboard de Programas

Como Diretor da agencia de fomento,
quero visualizar um dashboard consolidado dos programas de fomento,
para que eu possa avaliar o desempenho de cada programa e tomar decisoes estrategicas.

```gherkin
Funcionalidade: Dashboard de Programas

  Cenario: Visualizacao do dashboard com dados disponiveis
    Dado que o Diretor esta autenticado
    E existem programas com dados consolidados
    Quando acessa o dashboard de programas
    Entao o sistema exibe quantidade de projetos por programa, volume financeiro alocado e taxa de execucao

  Cenario: Filtragem por periodo
    Dado que o Diretor esta no dashboard de programas
    Quando seleciona o periodo de "2024-01-01" a "2024-12-31"
    Entao o sistema atualiza os graficos e indicadores para o periodo selecionado

  Cenario: Filtragem por instituicao
    Dado que o Diretor esta no dashboard de programas
    Quando seleciona a instituicao "UFES"
    Entao o sistema exibe apenas os dados de programas com projetos da instituicao selecionada

  Cenario: Exportacao do dashboard para PDF
    Dado que o Diretor esta visualizando o dashboard de programas
    Quando solicita exportacao em formato PDF
    Entao o sistema gera o arquivo PDF com os dados e graficos exibidos
    E disponibiliza o arquivo para download
```

### US-M018-002: Dashboard de Projetos por Edital

Como Servidor da Area Tecnica,
quero visualizar um dashboard de projetos agrupados por edital,
para que eu possa acompanhar a distribuicao e o andamento dos projetos financiados.

```gherkin
Funcionalidade: Dashboard de Projetos por Edital

  Cenario: Visualizacao de projetos por edital
    Dado que o Servidor da Area Tecnica esta autenticado
    E existem projetos vinculados a editais
    Quando acessa o dashboard de projetos por edital
    Entao o sistema exibe quantidade de projetos por edital, status dos projetos e distribuicao por instituicao

  Cenario: Filtro por edital especifico
    Dado que o Servidor esta no dashboard de projetos
    Quando seleciona o edital "Edital 01/2024"
    Entao o sistema exibe os indicadores detalhados daquele edital

  Cenario: Visibilidade restrita por escopo
    Dado que o Servidor da Area Tecnica possui escopo restrito
    Quando acessa o dashboard de projetos
    Entao o sistema exibe apenas os projetos dentro do seu escopo de atuacao (RN04)

  Cenario: Exportacao para Excel
    Dado que o Servidor esta visualizando o dashboard de projetos
    Quando solicita exportacao em formato Excel
    Entao o sistema gera o arquivo Excel com os dados tabulares
    E disponibiliza o arquivo para download
```

### US-M018-003: Dashboard de Indicadores Consolidados

Como Diretor da agencia de fomento,
quero visualizar indicadores consolidados de desempenho da agencia de fomento,
para que eu possa avaliar a eficiencia operacional e comparar resultados entre periodos.

```gherkin
Funcionalidade: Dashboard de Indicadores Consolidados

  Cenario: Visualizacao de indicadores consolidados
    Dado que o Diretor esta autenticado
    Quando acessa o dashboard de indicadores consolidados
    Entao o sistema exibe taxa de execucao financeira, tempo medio de concessao de bolsas, taxa de renovacao e numero total de bolsistas ativos

  Cenario: Comparativo entre periodos
    Dado que o Diretor esta no dashboard de indicadores consolidados
    Quando seleciona comparativo entre "2024" e "2023"
    Entao o sistema exibe os indicadores lado a lado com variacao percentual (RN06)

  Cenario: Calculo automatico de indicadores
    Dado que os dados transacionais foram atualizados no processamento diario
    Quando o sistema executa o calculo de indicadores
    Entao os valores dos indicadores sao recalculados automaticamente (RN05)
    E a data de ultimo calculo e atualizada

  Cenario: Tempo de carregamento aceitavel
    Dado que o Diretor acessa qualquer painel analitico
    Quando o sistema processa a requisicao
    Entao o painel e exibido em ate 5 segundos (RN08)
```
