## Contexto

Projetos sao iniciativas concretas vinculadas a editais. Cada projeto tem um coordenador responsavel (PessoaFisica do M008) que pode ser substituido com justificativa.

## User Stories

### US-M003-004 — Criar Projeto vinculado a Edital
Cadastro de projeto com titulo, resumo, coordenador e datas.

### US-M003-005 — Registrar Coordenador do Projeto
Vinculo de PessoaFisica como coordenador atual.

### US-M003-006 — Substituir Coordenador com Justificativa
Troca de coordenador com registro de justificativa e datas.
