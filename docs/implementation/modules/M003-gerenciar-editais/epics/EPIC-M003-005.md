# EPIC-M003-005 — Visao Operacional Consolidada

| Atributo | Valor |
|----------|-------|
| **Status** | Done |
| **Prioridade** | Must |
| **Dependencias** | Transversal (todos os EPICs anteriores) |
| **Operacao do contrato** | ConsultarVisaoOperacionalDoEdital |

## Contexto

Visao consolidada do edital com projetos, cotas e alocacoes. Consumida pelo Portal Coordenador (EP-06, EP-07) e pelos modulos M004, M009, M012-M015.

## User Stories

### US-M003-012 — Consultar Visao do Edital
Retorna edital com contadores de projetos, cotas e alocacoes.

### US-M003-013 — Consultar Projetos do Edital
Lista projetos com coordenador, status e alocacoes.

### US-M003-014 — Consultar Bolsistas do Projeto
Lista bolsistas alocados com modalidade, orientador e status.
